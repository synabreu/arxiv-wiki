# AGENTS.md

## Project goal
Generate a daily, public Markdown digest of ten notable arXiv AI papers.

## Rules
- Never invent claims, numbers, datasets, or benchmark results.
- Clearly state that analysis is based on title and abstract unless full text was parsed.
- Keep generated content readable for non-specialists while preserving technical terms.
- Every paper must link to its arXiv abstract and PDF.
- Do not redistribute PDF files.
- Add or update tests for ranking, parsing, or rendering changes.
- Keep secrets out of the repository. Use GitHub Actions secrets.
