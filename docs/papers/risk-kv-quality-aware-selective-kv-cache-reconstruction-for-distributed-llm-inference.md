## 한 문장 요약

RISK-KV는 두 개의 인접한 층에서 보유한 정확한 KV를 앵커로 삼아 능형 회귀(ridge regression)로 누락된 층의 attention 입력을 예측하고 원래 모델의 KV 투영을 접어(fold) 온라인에서 선택적으로 KV를 재구성하여 분산 LLM 추론에서 역사적 KV 저장·전송 비용을 줄이되 예측 품질 저하를 NLL 기반 리스크로 제어하는 방법이다.

## 해결하려는 문제

자동회귀 LLM 추론에서 긴 문맥·깊은 층·동시 요청 증가로 인해 역사적 KV 캐시가 커지며, 분산 환경에서 요청 이주(request migration)나 복구 시 전체 KV를 유지·전송하면 상태 오버헤드가 크고, 완전 토큰 재연산(token replay)은 추가 계산·지연을 야기한다. 기존 접근들은 토큰 선택, 양자화, 층 간 유사성 기반 공유 등으로 KV 저장을 줄이거나 압축하지만, 수치적 재구성 오류·레이어 유사성 등의 신호가 실제 언어모델 예측 성능(예: NLL)에 미치는 영향을 직접적으로 반영하지 못하고, 여러 층을 함께 재구성할 때의 비가산적 영향도 고려하지 않는다. 연구 질문은 "어떤 층(또는 층 그룹)을 보존하고 어떤 층을 재구성해야 캐시 절감과 예측 품질 간의 바람직한 절충을 달성할 수 있는가"이다.

## 핵심 기여

- 사전학습 모델을 변경하지 않고 두-측(양측) 층 앵커를 이용해 누락된 층의 attention 입력을 능형 회귀로 예측하고 원래 모델의 KV 투영 행렬과 합성(접기)하여 온라인에서 직접 복원 가능한 KV를 생성하는 재구성 방법을 제안함(중간 히든 상태 저장 불필요).
- 실제 KV 교체가 일으키는 예측 손실(교체 후 NLL 변화)을 기능적 리스크로 정의하고, 각 후보 그룹의 단독 리스크를 측정한 뒤 리스크당 저장 절감 비율로 정렬하여 경로 기반(2G 평가) 탐색과 부트스트랩 기반 상한(90%) 품질 게이팅으로 재구성 토폴로지를 선택하는 적응적 선택 절차를 제안함.
- 학습된 예측기와 모델의 KV 투영을 선형 결합(접기)하여 온라인에서 중간 히든을 명시적으로 물질화하지 않고도 직접 pre-RoPE 키/값을 생성함으로써 예측기 저장 및 온라인 중간 표현 비용을 줄이는 구현 경로를 제시함.
- 독립 테스트에서 대표적 구성들이 역사적 KV의 18.2%–33.3%를 생략하면서 퍼플렉시티 변화가 0.5% 미만임을 보였고(테이블·그림으로 상세 제시), 로컬 요청 복구(512 토큰 히스토리)에서는 Token Replay 대비 1.51×–3.31×의 속도 향상을 달성함으로써 실용적 잠재력을 입증함.

## 접근 방법

* 아키텍처: 대상은 L층 Transformer(decoder)이며 GQA(Grouped-Query Attention) 환경을 가정한다.
* 각 층은 attention 정규화 후의 히든 H_ℓ(사전-RoPE 투영 입력)을 갖고, 원래 KV 투영은 Y_ℓ = H_ℓ W_ℓ + 1 b_ℓᵀ로 표기된다.
* 오프라인 캘리브레이션: 후보 복구 그룹 G_g(보통 두 층 단위)를 정의하고, 해당 그룹의 양측(왼·오) 앵커 층에서 보유한 pre-RoPE 키·값을 역 RoPE(키에만)로 되돌려 입력 특징 X_A로 연결(Concat)한다.
* 레이블은 대상층들의 정규화된 히든 HT의 연결이다.
* 알고리즘: 능형 회귀(ridge regression, 인터셉트 포함)를 학습해 ˆH_T = X_A A_T + 1 b_Tᵀ로 예측한 뒤 원래의 블록 대각 KV 투영 P_T를 적용해 예측된 pre-RoPE KV ˆZ_pre_T = ˆH_T P_T + 1 c_Tᵀ를 얻는다.
* 이 두 선형 변환은 합성되어 folded predictor BT = A_T P_T, d_T = b_T P_T + c_T로 표현되어 온라인에서 앵커 X_A로부터 직접 pre-RoPE KV를 생성(수식 6–8).
* 온라인 추론: 선택된 토폴로지 S만큼의 층들에 대해 오프라인 예측기(접힌 형태)를 이용하여 누락된 KV를 재구성하고 RoPE를 재적용한 뒤 완전한 KV 캐시를 조립해 디코딩을 계속함.
* 선택 절차(오프라인): 모든 후보 그룹의 단독 리스크 ρ_g(교체 후 평균 NLL 차이) 측정, 리스크/저장 가능 바이트 비율로 오름차순 정렬(π).
* 이 순서대로 접두(prefix) 형태의 결합 후보 S_k = {π1..πk}를 평가(각 조합에 대해 실제 joint ∆NLL 재측정)하여 후보 집합 C 형성(총 평가수는 2G).
* 각 후보에 대해 페어드 요청 손실을 부트스트랩해 90% 단측 상한 U_0.90(S) 계산하고 허용 평균 NLL 증가 ε를 만족하는 후보들 중 가장 많은 KV를 생략하는 S* 선택(품질 게이트).
* 계산·통신 비용 모델: 저장 절감 M_saved, 예측기 저장 M_pred 계산(식 13–16) 및 복구 지연 모델(식 17–20) 제시.

## 주요 결과

- 실험 셋업: 모델 Qwen2.5-0.5B-Instruct(24층), Qwen2.5-1.5B-Instruct(28층), TinyLlama-1.1B-Chat-v1.0(22층). 데이터는 WikiText-2, 히스토리 길이 512 토큰, teacher-forced로 다음 512 토큰의 NLL 측정. 후보 그룹 수는 각각 5, 6, 5(two-layer 그룹 단위). 모든 실험에서 기본 모델 파라미터는 고정(frozen).
- 대표적 테스트 결과(테이블 I, 독립 테스트, 24 paired 요청): Qwen2.5-0.5B: G2,G3,G4,G5 복원(생략된 KV 2.0 MiB, 33.3%), Exact PPL 22.760 → RISK-KV PPL 22.801, ∆NLL = 0.001622 (95% CI [−0.000571, 0.003962]). Qwen2.5-1.5B: G2,G3,G5,G6 (4.0 MiB, 28.6%), Exact PPL 15.205 → 15.183, ∆NLL = −0.000207 (95% CI [−0.008627, 0.006686]). TinyLlama-1.1B: G2,G5 (2.0 MiB, 18.2%), Exact PPL 12.681 → 12.722, ∆NLL = 0.003645 (95% CI [−0.002192, 0.008021]).
- 독립 평가 전반: 대표적 구성들은 테스트에서 역사적 KV 18.2%–33.3%를 생략하면서 퍼플렉시티 변화가 0.5% 미만으로 관찰됨(본문·초록).
- 품질 게이트 비교(테이블 II, TinyLlama, ε=0.002, 24 요청): Mean Gate(평균 기반) 위반률 41.7% (10/24), 평균 KV 저장 1.667 MiB; Upper-90(부트스트랩 상한) 위반률 8.3% (2/24), 저장 0.667 MiB; Stable-split(독립 확인셋 추가) 위반률 0%, 저장 0.333 MiB. 이는 보수적 게이트가 위반을 줄이되 저장량을 줄이는 트레이드오프를 보여줌.
- 예측기 저장(테이블 III): 접기(folded) 전 원본 ridge 파라미터는 매우 큼(예: TinyLlama 원본 32.016 MiB/그룹). Folded FP32로 줄이면 Qwen0.5 ~2.002 MiB, Qwen1.5 ~8.004 MiB, TinyLlama ~8.004 MiB; FP16으로는 각각 절반. 논문은 한 그룹 당 평균 파라미터 크기를 보고하며, 실제 배포 이익은 여러 요청 간 예측기 공유 여부에 따라 달라짐. 예: Qwen0.5 구성에서 한 요청당 생략된 KV(2 MiB) 대비 접힌 FP32 예측기 용량은 약 4배여서 다수의 요청이 예측기를 공유해야 순절감이 발생함.  
로컬 복구 지연 실측(RTX 3060 Laptop GPU, 배치1, 512-token 히스토리, 8 요청 모델별): Token Replay 평균 지연(ms) = {Qwen0.5:60.66, Qwen1.5:125.41, TinyLlama:114.07}; RISK-KV 평균 = {40.09, 48.99, 34.50} → 속도향상 1.51×, 2.56×, 3.31× 각각(그림 6).

## 한계

- (저자가 명시한 한계) 무선 크로스-노드(실제 네트워크) 이주 시나리오와 장거리 전송 조건에 대한 실험은 수행하지 않았음(본문 명시). 또한 현재 실험에서는 이후 디코딩 단계에서 완전 KV 캐시가 여전히 물질화(materialized)되어 실전 분산 파이프라인의 전체 비용·지연을 완전히 평가하지 못함.
- (실험·방법에서 합리적으로 확인되는 제약) 오프라인 캘리브레이션은 모델·레이어·재구성 메커니즘에 특화되어야 하며, 탐색은 리스크 순서의 단일 경로에 제한하므로 전역 최적성을 보장하지 않음(논문에서 명시). 예측기 저장 비용이 단일 요청이 절약하는 KV보다 클 수 있어 이득은 예측기 공유 수(N 요청)에 크게 의존함(본문 계산 예시). 캘리브레이션·품질 게이팅은 평균적 리스크를 통제하나 개별 요청 민감도 차이로 인해 여전히 예산(ε)을 위반하는 요청이 존재할 수 있음(테이블 II). 실험은 소형/중형 모델(≤1.5B)과 512-token 문맥에 국한되어 있으며, 더 긴 컨텍스트·대형 모델·실제 분산 네트워크 조건에서의 일반화는 확인되지 않음.

## 개발자 관점

- 재현·학습: 오프라인 캘리브레이션 데이터(히스토리 길이, teacher-forced 다음 토큰 범위)는 모델마다 분리해서 준비해야 하며 능형 회귀 학습(인터셉트 포함)을 통해 각 후보 그룹별 단독 리스크를 측정한 뒤 리스크 기반 순서로 접두형 결합을 재평가해야 함(총 평가 수 2G). 논문은 람다(정규화 계수) 등 회귀 하이퍼파라미터 상세값을 제공하지 않으므로 재현 시 튜닝 필요.
- 예측기 저장·배포: 접힌(folded) 예측기를 FP32/FP16으로 저장 가능하며(논문 표 참조) 예측기가 대상 노드에 미리 배치되어 있으면 이주·복구 시 전송 오버헤드를 줄일 수 있다. 다수 요청이 같은 모델·토폴로지를 쓴다는 가정 하에 예측기 공유를 통해 순 이득이 발생하므로 배치·다중 동시요청 상황을 고려한 배포 전략이 필요함.
- 온라인 복구 구현: 온라인 단계는 유지할 정확한 앵커(양측) 층의 KV만 전송·보존하고 역-RoPE·특징 조합→접힌 예측기→RoPE 재적용 순으로 pre-RoPE KV를 생성해 실제 키는 RoPE 적용 후 캐시에 넣는다. 중간 히든을 물질화하지 않으므로 메모리·계산 흐름을 단순화할 수 있음.
- 비용·성능 모니터링: 접힌 예측기 크기 대비 요청당 생략 KV 크기, 예측기 공유 수, 네트워크 대역폭(예시로 논문은 100 Mbps 가정)·전송 지연을 계산해 배포 이득을 예측해야 한다. 또한 품질 게이트(Upper-90 등)를 도입해 캘리브레이션 표본의 불확실성을 반영하고 필요 시 안정성 확인용 독립 셋(Stable-split)을 사용해 엄격한 적용을 할 것.
- 안전성·롤백: 재구성된 KV는 출력 분포를 변경할 수 있으므로(일부 구성에서 ∆NLL가 양/음 모두 관측됨) 운영에서는 품질 예산을 초과하는 요청에 대해 정확한 KV로 폴백(fallback)하는 경로를 유지해야 하며 이상 출력·드리프트를 모니터링하는 계측을 포함해야 함.

**근거 범위:** 본 분석은 제공된 논문 PDF 본문(모든 페이지)의 텍스트를 근거로 작성되었다. 수치·표·그림(테이블 I–III, 그림 3–6)과 방법·알고리즘(식(2)–(20), Algorithm 1)은 PDF에서 추출된 내용을 직접 인용·요약하였다. PDF 본문에 명시되지 않은 하이퍼파라미터(예: ridge 정규화 계수 λ, 학습 반복 수 등)나 일부 시스템 상세(무선 실험의 실제 네트워크 조건)는 문서에 포함되어 있지 않아 본 분석에서 생성하지 않았으며, 배포 이득 계산에서 논문이 사용한 가정(예: 100 Mbps 가정)은 본문에서 예시로 제시된 내용임을 명시한다.
