## 한 문장 요약

사전학습된 인과적(transformer) 모델에 대해 추가 학습 없이 슬라이딩-윈도우 KV 캐시를 유지하는 추론(rolling KV inference)을 적용하여, 이전에 계산된 KV 상태가 윈도우 밖의 정보(원본 토큰)를 이후 토큰에 전달하고 검색에 유용한지를 실험적으로 검증한다.

## 해결하려는 문제

기존 방식에서는 고정 크기 KV 캐시만 유지하며 긴 시퀀스를 순차 처리할 때 윈도우 밖의 정보가 손실된다고 가정한다. 그러나 캐시에 저장되는 키/값은 이전 문맥에서 계산되므로 그 자체로 더 먼 과거의 정보를 내포해 이후 토큰에 전달할 수 있다. 본 논문은 (1) 캐시를 계속 유지하는 것이 원본 토큰을 재계산(recompute)하는 대안보다 실제로 검색 성능을 향상시키는지, (2) 캐시를 통해 전달된 정보가 얼마나 멀리(윈도우를 벗어난 이후에도) 유효하게 남는지, (3) 모델 아키텍처(예: 슬라이딩-윈도우 어텐션)로 학습된 모델이 이러한 정보 유지에 유리한지라는 질문을 다룬다.

## 핵심 기여

- 다섯 개의 공개 가중치 모델(Qwen, Llama, Mistral, Muse Glimmer 포함)에 대해 슬라이딩-윈도우 KV 추론 특성을 비교하는 일련의 실험을 수행함.
- 이미 계산된 이전 KV 상태를 유지하는 방식이, 최종 고정 윈도우를 원시 토큰으로부터 재계산하는 방식보다 검색 성능을 전반적으로 향상시킨다는 실험적 증거를 제시함.
- '잠재 정보 중계(latent information relay)' 현상을 측정하여, 일부 모델(Muse Glimmer 및 Mistral 7B)이 관련 소스 토큰이 캐시에서 사라진 이후에도 정보를 회복할 수 있음을 관찰함.
- 슬라이딩-윈도우 어텐션을 공개 아키텍처에 포함한 모델들이 정보 보존 측면에서 강한 성능을 보인다는 연관을 보고하고, 이는 슬라이딩-윈도우로 학습하는 것이 정보 유지에 기여할 수 있다는 가설을 제기함.
- 슬라이딩-윈도우 KV 추론을 사전학습 모델에 추가 학습 없이 적용하여 실무적·추론적 관점에서의 유용성을 평가하는 방법론적 실험 설계를 제안함.

## 접근 방법

* 사전학습된 인과적 트랜스포머들에 대해 추론 시 슬라이딩-윈도우 KV 캐시를 유지하는 방식으로 시퀀스를 순차 처리한다.
* 비교 실험으로는 (A) 이전에 계산된 KV 상태를 롤링(유지)하는 방식과 (B) 마지막 고정 크기 윈도우만을 원시 토큰으로부터 재계산(recompute)하는 방식이 사용된다.
* 다섯 개 공개 모델(Qwen 계열, Llama 계열, Mistral 7B, Muse Glimmer 등)을 대상으로 동일한 절차로 테스트하여 '유지했을 때'와 '재계산했을 때'의 검색 성능 차이를 측정하고, 소스 토큰이 캐시에서 사라진 이후에도 정보가 회복되는지(정보가 얼마나 멀리 전달되는지)를 추가 실험으로 평가한다.
* 실험은 추가 학습 없이 순수히 추론 절차(캐시 유지 vs 재계산)의 차이만을 비교하는 방식으로 설계되었다.

## 주요 결과

- 테스트한 모든 모델에서 '이전에 계산된 KV 상태를 유지'하는 방식이 '최종 고정 윈도우를 원시 토큰으로부터 재계산'하는 방식보다 검색 성능이 향상됨(정량 수치는 본문에 제시되지 않음).
- 모델별로 차이가 있었으며, Muse Glimmer와 Mistral 7B에서 가장 강한 '잠재 정보 중계' 현상이 관찰되어 관련 소스 토큰이 캐시에서 사라진 이후에도 정보를 회복할 수 있었음.
- 실험에 사용된 모델 집합은 Qwen, Llama, Mistral, Muse Glimmer 등 공개 가중치 모델 5종으로 구성됨(개별 모델명 및 정확한 구성은 본문에서 명시됨).
- 슬라이딩-윈도우 어텐션을 아키텍처에 포함한 모델들이 정보 유지 능력에서 상대적으로 우수한 경향을 보였음(상관 관계 관찰).

## 개발자 관점

- 추론 최적화: 롤링 KV 캐시를 유지하면 재계산 비용을 줄이는 동시에 정보 검색 성능을 개선할 수 있으므로, 대규모 모델을 배포할 때 KV 재사용 전략을 우선 고려할 가치가 있음.
- 모델 선택: 슬라이딩-윈도우 어텐션을 아키텍처에 포함해 학습된 모델은 윈도우 밖의 정보를 더 잘 보존할 가능성이 있어, 긴 문맥 유지가 중요한 응용에서는 해당 특성을 가진 모델을 우선 검토해야 함.
- 재현성 요구사항: 재현을 위해서는 사용된 평가 데이터셋, 프롬프트/프롬프트 템플릿, 토크나이저 및 윈도우 크기·롤링 정책, 정확한 비교 절차(캐시 초기화 시점 등)를 명시적으로 확보해야 함.
- 프라이버시·안전성: KV 캐시가 윈도우를 벗어난 정보까지 전달할 수 있으므로, 민감 정보가 포함된 이전 컨텍스트가 의도치 않게 이후 응답에 영향을 주거나 유출될 위험을 고려해 캐시 관리(세션 분리·암호화·삭제 정책)를 설계해야 함.
- 비용·성능 트레이드오프: 캐시를 유지하면 토큰 재계산 비용을 줄일 수 있으나 캐시 저장·관리 비용과 메모리 사용(고정 크기 KV 유지)·버그(의도치 않은 정보 보존)에 유의해야 함.
