## 한 문장 요약

UAV 이미지에서 YOLO 기반 객체검출(두 클래스: cattle-head, cattle-back)과 SAM 분할을 결합해 먹이홈(feed bunk)을 기하학적 기준선으로 설정하고 가로·종방향 거리·간격 지표(RMSD, CV, GR, 클러스터 수)로 급이대 정렬성과 공간분포를 정량화하는 프레임워크를 제안한다.

## 해결하려는 문제

현장 급이 환경에서 먹이홈 주변의 소 분포와 정렬성 평가는 기존에 주로 사람의 주관적 시각관찰에 의존해 확장성이 낮고 편향·비효율 문제가 있다. UAV 기반 상공 영상은 넓은 영역을 비접촉으로 관찰할 수 있으나, 소의 자세·방향성·부분 폐색 및 다양한 조명·외형 변화 때문에 정확한 검출과 먹이홈을 기준으로 한 해석 가능한 공간지표 추출이 어렵다. 본 연구는 UAV 이미지에서 머리(head)와 등(back)를 구별해 검출 성능을 확보하고, SAM으로 먹이홈을 분할한 뒤 기하학적 투영·거리 계산으로 즉시(이미지 수준) 정렬성과 간격의 규칙성·응집(클러스터링)을 정량화하는 것을 목표로 한다.

## 핵심 기여

- UAV 기반의 비침습적 컴퓨터비전 프레임워크 제안: cattle-head와 cattle-back의 이중 클래스 검출과 SAM 기반 먹이홈 분할을 결합해 먹이홈 기준의 기하학적 지표로 공간분포를 정량화함.
- YOLO 계열 모델(YOLOv8, YOLOv11)의 다양한 크기( nano→x )에 대한 비교평가 수행 및 실제 파이프라인 용도로 YOLOv8 small(v8s)를 선정함.
- Segment Anything Model(SAM, vit_h)를 이용한 먹이홈 마스크 추출 방법 제시 및 마스크에서 중앙 수직선 적합(직선 근사)을 통해 Ax+By+C 형태의 기준선 산출 절차 제시.
- 검출 결과(머리 중심점) 기반으로 가로(수직) 편차와 종(연장선상) 간격을 계산하는 기하·통계 지표(RMSD, Max Dev, CV, Gap Ratio)와 DBSCAN을 이용한 클러스터 검출을 도입해 즉시 이미지 수준의 점수/대시보드로 시각화함.
- 실제 상업적 사양의 데이터(232장, 5,027개 인스턴스)를 공개 데이터셋으로 사용해 검출 성능(예: v8s mAP50=84.30% ±1.00, mAP50-95=35.50% ±0.90)과 공간지표(예: 예시 정렬/불규칙 이미지의 RMSD=105.54 cm vs 425.97 cm, CV=42.70% vs 96.31%, 클러스터수 0 vs 2)를 제시함.

## 접근 방법

* 데이터수집·주석: 상업용 사육지(브라질 Campanário Farm)에서 DJI Phantom 4 Advanced(4864×3648)로 고도 약 15 m 비행 촬영, GSD≈4 mm/px로 추정.
* 전체 232장 이미지를 연대순으로 훈련(97장), 검증(47장), 테스트(88장)로 분할하고 LabelMe로 cattle-head와 cattle-back 박스 레이블(총 5,027 인스턴스)을 수동 주석함.검출기 학습: YOLOv8 및 YOLOv11의 모든 크기(nano, small, medium, large, x) 변형을 비교.
* 입력 해상도 640×640, 배치 16, 최대 50 epoch, patience 15로 훈련(하드웨어: AMD Ryzen 7 9700X, 32GB, NVIDIA RTX 5060 Ti 16GB).비교 기준은 mAP50 및 mAP50-95(평균 및 95% 신뢰구간, 10회 반복 학습 결과 평균) 및 추론시간.추론·공간분석 파이프라인: 선택된 검출기(YOLOv8 small)는 NMS IoU=0.10 적용 후 최종 바운딩 박스 중심을 점으로 취함.
* SAM(vit_h)를 사용해 먹이홈 마스크(폴리곤)를 얻고 그 폴리곤의 수직 중앙선을 직선(Ax+By+C=0)으로 선형 적합하여 기준선을 산출.
* 각 검출 머리점에 대해 기준선까지의 수직거리 di(식 1)와 점의 기준선으로의 직교투영을 계산하고, 투영점의 기준선 상 좌표 si를 단일차원으로 환원하여 인접 gap gj 계산.
* 가로분산(대응: RMSD, Max Dev)과 종방향 균일성(µg, σg, CV, GR) 지표를 계산하고, DBSCAN(ϵ=0.5·평균간격, minPts=3)을 적용해 클러스터 수를 산출.
* 대시보드를 통해 원영상, 투영점, 거리히스토그램, 간격분석, 1D 클러스터 분포를 시각화.

## 주요 결과

- 데이터셋: 232 이미지, 총 5,027 바운딩박스(훈련 1,911 / 검증 1,137 / 테스트 1,979 인스턴스; 표 기준). 촬영 고도 ≈15 m, GSD ≈4 mm/px(논문에서 근사값으로 사용).
- 검출 성능(대표값, 평균 ±95% CI, 10회 학습 반복): YOLOv8 small(v8s) 전체 mAP50 = 84.30% ± 1.00; class별 mAP50: cattle-back 91.70% ± 0.40, cattle-head 76.80% ± 2.10. v8s mAP50-95 = 35.50% ± 0.90. 일부 중간 크기 모델(v8m, v11l 등)은 mAP가 약간 더 높았으나(예: v8m mAP50=85.80% ±0.50) 데이터셋 크기와 구현 안정성 고려하여 v8s 선택.
- 추론시간: 논문에서 RTX 5060 Ti GPU 기준으로 약 2.7 ms/이미지(요약부 표기) 수준으로 보고되며, 모델별 추론시간과 mAP를 비교한 그래프 제시(더 경량 모델이 빠름).
- SAM 분할의 일관성: SAM으로 분할한 먹이홈선과 수동 주석선의 각도 편차는 0.44° ± 0.68°, 즉 합리적 일치 보임.
- 공간지표(예시 이미지 두 건): 정렬(regular) 예시: 평균 수직거리 102.78 cm, 표준편차 23.97 cm, RMSD 105.54 cm, Max Dev 127.23 cm; 간격 평균 70.54 cm, std 30.12 cm, CV 42.70%, GR 0.0509, 클러스터 수 0. 불규칙( irregular) 예시: 평균 수직거리 293.18 cm, std 309.03 cm, RMSD 425.97 cm, Max Dev 973.46 cm; 간격 평균 109.97 cm, std 105.92 cm, CV 96.31%, GR 0.0387, 클러스터 수 2. 18개 이미지(각 이미지에 ≥5 검출 머리)를 그룹화한 결과, 클러스터가 있는 이미지군은 없는 이미지군에 비해 RMSD와 CV가 현저히 높음(예: RMSD 평균 615.30 cm vs 163.41 cm).

## 한계

- 저자가 명시한 한계: 데이터셋 규모가 비교적 작아(232장) 결과는 타당성 근거(feasibility)로 해석되어야 하며 통계적으로 강력한 일반화 결론을 내리기 어렵다. 정렬/불규칙 시나리오는 연구진의 질적 판단으로 정의되었고, 전문가의 먹이홈 스코어나 동물생체지표와 직접 검증되지 않았다. 실험은 직선형 먹이홈을 가정하여 직선(Ax+By+C)으로 근사했으며, 곡선형 또는 L자형 배치에는 방법 적응이 필요하다.
- 본문에서 합리적으로 확인되는 제약(저자와 구분): SAM 분할은 수동으로 근사 지점을 줘서 마스크를 얻는 과정으로 보이며(논문은 'approximate indication' 언급), 완전 자동화된 분할·전처리 파이프라인이 구현된 것은 아니다. GSD는 고도 기록과 지형 불균일로 약간 변동하며 논문은 ≈4 mm/px를 근사 인수로 사용하므로 물리 단위로의 절대 정확도는 제한된다. 학습관련 세부 하이퍼파라미터(예: 학습률, 옵티마이저, 데이터증강 방식 등) 일부는 본문에 명시적 수치가 부족해 재현시 추가 결정이 필요하다. 추가로, 더 큰 모델(v8x, v11x)에서 성능 저하가 관찰되었는데 이는 과적합 가능성과 데이터량 제약을 시사한다. 임베디드(엣지) 장치에서의 실제 배포 성능 및 전력/실시간성 평가는 논문에서 실험적으로 검증되지 않았다.

## 개발자 관점

- 재현성: 데이터와 레이블(버전 2) 공개(저자 GitHub 링크 명시). 재현 시 주요 설정: 입력 640×640, 배치 16, 최대 epoch 50, patience 15, NMS IoU=0.10, 하드웨어 RTX 5060 Ti에서 성능 측정. 다만 학습률·옵티마이저·데이터증강 세부는 본문에 명확히 기술되어 있지 않으므로 재현을 위해서는 기본적으로 사용된 프레임워크(논문은 YOLO 공식 구현권장) 또는 저자에게 문의해야 함.
- 모델선택·규모: 소규모(약 200장) 이미지 데이터셋에서는 small/medium급의 YOLO 모델이 성능·안정성 면에서 유리하고, 매우 큰 모델은 과적합 우려가 있으므로 모델 크기 선택 시 데이터 규모를 고려해야 함.
- 지표·단위 변환: 물리 단위(cm) 계산을 위해 GSD≈4 mm/px를 사용했으나 촬영 고도·지형 변화로 GSD가 변동하므로 현장 배포 시에는 고도·카메라 캘리브레이션 또는 지면기준 표식으로 GSD를 재확인해야 함.
- 세그멘테이션: SAM(vit_h)을 활용하면 빠르게 먹이홈 폴리곤을 얻을 수 있으나, 완전 자동화하려면 프롬프트 자동화(예: 사전 정의된 점/선 추정) 또는 전용 세그멘테이션 학습이 필요함. SAM 출력에서 중앙 수직 중간점을 추출해 직선 적합으로 기준선을 계산하는 방식은 구현이 비교적 단순하고 안정적이지만 먹이홈이 곡선인 경우에는 대체 기준(곡선 피팅, 곡선 좌표계 변환)이 필요함.
- 공간지표·클러스터링: DBSCAN 설정(ϵ = 0.5·평균간격, minPts = 3)을 사용하면 로컬 응집을 검출 가능. 운영 환경에서 ϵ·minPts는 집단밀도와 관찰 고도에 따라 튜닝 필요. 간격 지표(CV, GR)와 RMSD는 즉시성(단일 프레임) 지표로 유용하나 장기 행동·섭취량과 직접 연계하려면 시간축 추적(트래킹)과 먹이량 데이터가 필요함.위험·윤리·안전: 연구는 비침습적 UAV 영상만 사용했고 동물 취급을 수반하지 않음으로 윤리적 부담이 낮지만, 실제 드론 운용 시 가축 스트레스와 안전(낙하·충돌)을 고려해 고도·비행경로·비행시간을 설계해야 함.

**근거 범위:** 분석은 제공된 논문 PDF 본문(페이지 1–12) 기반으로 작성함. 표·수치·절차(데이터셋 크기, mAP 수치, 하이퍼파라미터, GSD 근사값, RMSD·CV·클러스터 결과, SAM 각도편차 등)는 본문 표와 본문 서술에서 직접 추출함. 다만 학습 세부 하이퍼파라미터(예: 학습률, 옵티마이저, 데이터증강의 정확한 종류)는 본문에 명시되지 않아 확인 불가했고, SAM의 구체적 프롬프트 방식(정지점 자동화 여부)은 'approximate indication'으로 기술되어 있어 완전 자동화 절차는 본문에서 명확히 확인되지 않음.
