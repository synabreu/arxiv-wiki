## 한 문장 요약

Agile-WAM은 시각 및 촉각( TacFF ) 관측을 공유 잠재공간으로 융합한 뒤, vision-tactile-to-action 직접 흐름-매칭(flow-matching) 백본과 멀티-호라이즌 멀티모달 예측을 통해 접촉이 많은 조작에서 저지연 고정밀 행동 생성을 수행하는 경량화된 World Action Model이다.

## 해결하려는 문제

기존의 World Action Model(특히 촉각을 포함한 최근 연구)은 접촉이 많은 물리적 상호작용을 모델링하기 위해 대규모 사전학습된 생성 모델(비디오 백본 등)에 의존하는 경우가 많아 추론 시 계산·메모리 오버헤드가 크고, 로봇의 온보드 자원이나 높은 제어 주파수 요구를 충족시키기 어렵다. 또한 시각과 촉각 신호는 서로 다른 시간적 특성을 가지는데(시각은 인접 프레임간 중복이 크고 촉각은 접촉 시 급변함), 동일한 예측 호라이즌을 적용하면 두 모달리티의 동적 특성에 부적합한 감독 신호가 되어 세계 모델의 학습·제어 성능을 저해할 수 있다. 연구 질문은 '대규모 백본에 의존하지 않으면서도 촉각을 포함한 멀티모달 세계-동작 모델을 경량·저지연으로 설계하여 접촉이 많은 조작에서 높은 성공률과 실시간 제어를 달성할 수 있는가?'이다.

## 핵심 기여

- vision·tactile·proprioceptive 관측을 공유 잠재공간으로 융합하고, 이 잠재를 흐름-매칭의 source로 사용하여 action chunk와 미래 시각/촉각 잠재를 공동으로 생성하는 경량 vision-tactile-to-action flow-matching 백본(대형 사전학습 백본을 사용하지 않음)을 제안함.
- 시각과 촉각의 본질적 시간해상도 차이를 반영한 multi-horizon multimodal prediction을 도입하여 시각은 더 긴 호라이즌(hvis), 촉각은 다음 프레임(htac=1)으로 감독함으로써 시각·촉각의 서로 다른 동역학을 효과적으로 학습하도록 설계함.
- 액션 오토인코더(action encoder/decoder)를 함께 학습하고, 학습 중 ODE로 생성된 액션 잠재를 디코딩하여 행동 공간 상의 재구성 손실(Lact)을 추가로 적용함으로써 훈련시 목표 잠재와 추론시 생성된 잠재 간 차이를 줄여 안정적인 행동 생성을 도입함.
- 시뮬레이션(ManiFeel 기반) 9개 작업과 실제 5개 접촉-풍부 조작 작업에서 평가하여, 기존 강력한 베이스라인들을 능가하는 성공률과 낮은 추론 지연을 보임(실험적 근거 및 상세한 소거실험 포함).
- 경량 설계(간단한 MLP flow, ResNet-18 기반 인코더 등)와 직접 flow-matching(조건 주입을 반복하지 않음)을 통해 복잡한 cross-attention 기반 조건화 없이도 실시간 제어에 적합한 추론 효율성을 확보함.

## 접근 방법

* 아키텍처: 입력으로 RGB 이미지(Ovis_t), TacFF 촉각 신호(Otac_t), 및 proprioceptive 상태(qt)를 별도 인코더(시각: ImageNet 사전학습 ResNet-18, 촉각: 신축 ResNet-18)를 통해 특징 추출 후 선형 투영으로 결합하여 공유 소스 잠재 z0를 생성한다.
* 액션은 고정 길이의 액션 청크 at:t+H(논문에서 H=16)를 autoencoder(Ea, Da)로 잠재 za_1로 표현한다.
* Flow-matching: 소스 z0와 타겟 z1 = [za_1, zvis_1, ztac_1]을 동일 차원으로 구성하고 선형 보간 z_tau=(1-τ)z0+τz1에 대해 속도장 v_theta(z_tau, τ)를 MLP로 학습하여 L_FM = E\|\|v_theta - (z1 - z0)\|\|^2을 최소화한다.
* 멀티-호라이즌 예측: 시각 잠재 타겟은 h_vis(논문 설계: h_vis = h, 실행되는 액션 길이와 일치)로 더 긴 시차의 이미지 잠재를 목표로 하고, 촉각은 htac=1로 다음 프레임 예측을 목표로 하여 L_vis 및 L_tac를 잠재공간 L2 손실로 감독한다.
* 액션지도: 액션 오토인코더 재구성 손실 L_AE과 ODE로 생성된 잠재를 디코딩하여 행동 공간에서 직접 비교하는 Lact를 추가한다.
* 전체 손실: L = λ_FM L_FM + λ_AE L_AE + λ_act Lact + λ_vis L_vis + λ_tac L_tac.
* 학습·추론 절차: 학습 시 z0와 라벨 잠재(z1)를 구성해 흐름을 학습하고 액션 재구성 및 잠재 예측 손실을 함께 최적화한다.
* 추론 시 현재 관측을 한 번 인코딩하여 z0를 얻은 뒤 ODE dz/dτ = v_theta(zτ,τ), z_0 = z0을 τ∈[0,1]에서 통합(논문에서는 추론에 explicit Euler, 6 단계 사용)하여 z1을 얻고 ˆza_1을 디코딩해 액션 청크를 생성, 그 중 처음 h=8개 행동을 실행하고 재계획한다.

## 주요 결과

- 시뮬레이션(ManiFeel) 9개 작업에서 Agile-WAM이 대부분 작업에서 VITA, VITA-VT, Tactile-WAM, DP 계열 등 기존 방법보다 높은 성공률을 기록함(표 I에 작업별 성공률 및 표준편차 수록). 예: Bulb Screw 92.67±2.49 (Agile-WAM) vs VITA 71.33±0.94; Nut Bolt Threading 92.67±2.49 (Agile-WAM) vs VITA 86.67±4.71. (표 I 전체 수치 본문 참고).
- 실험적 실제(Real-world) 5개 작업 평가에서 논문이 보고한 주요 수치: 실제 실험 전체에서 저자 주장 '전체 성공률 상대 향상 29.4%'(본문 초록/서술). 작업별 성능(각 20 에피소드): Gear Assembly 0.80 (16/20), Peg Insertion 0.55 (11/20), Power Plug Insertion 0.65 (13/20), Internet Cable Insertion 0.30 (6/20), Internet Cable Unplugging 0.85 (17/20) — 모두 Agile-WAM의 결과(표 II).
- 추론 지연 및 제어 주파수(표 III): Agile-WAM 평균 추론 시간 10.35±0.14 ms(논문 표), 이는 VITA(9.71±0.11 ms)와 유사하며 DP 계열(≈408 ms)이나 TAAM(≈636 ms)에 비해 수십 배 낮은 지연을 보임. 제어 주파수로 환산 시 Agile-WAM은 약 96.6 Hz, VITA 약 103 Hz, DP 계열은 ≈2.4 Hz 수준으로 보고됨.
- 소거연구: (i) 액션-미래 상태의 공동 예측을 제거한 변형보다 공동 예측이 성능을 향상시킴(단순히 잠재 용량 증가 효과와 구분됨), (ii) 입력에 양쪽 모달리티가 있을 때 시각/촉각 중 하나만 예측하면 성능 저하가 발생하고, 둘을 모두 예측할 때 최적 성능(그림 5(b)), (iii) 동일 호라이즌 사용이나 양쪽을 next-frame으로 예측하는 대안에 비해 multi-horizon 설계가 더 우수(그림 5(c)), (iv) ODE 통합 단계는 논문에서 6단계 explicit Euler를 사용했으며, 확산 기반 DP는 100 denoising 단계로 훨씬 긴 추론시간을 소비.

## 한계

- 저자가 명시한 한계: 실제 시스템에서 '정책의 최대 제어 주파수'는 본 논문에서 측정한 추론 지연 이외에도 로봇 제어 인터페이스, 센서 샘플링 레이트 등의 제약에 의해 추가적으로 제한될 수 있다고 논문 본문에서 언급함.
- 본문으로 합리적으로 확인되는 제약(저자가 직접 명시하지 않은 한계로 구분): (a) 평가가 ManiFeel 벤치마크의 9개 시뮬·5개 실제 작업 및 특정 센서(시뮬 TacFF 10×14×3, 실제 32×32 압력센서)·로봇 플랫폼(Franka/ Flexiv Rizon 4)에 국한되어 있어 다른 작업군·센서·로봇으로의 일반화(특히 다른 촉각 센서 종류나 해상도) 성능은 검증되지 않았음, (b) 대형 사전학습 백본을 사용하지 않는 경량 학습 설계는 추론 효율을 높였으나 대규모 데이터에서의 사전학습된 표현 이점을 포착할 수 있는지에 대한 비교는 본문에서 제한적으로 다루어짐, (c) 학습은 데모 기반(시뮬: 20–50 데모, 실제: 50 데모) 설정에서 수행되며 대규모 자율수집·강화학습 기반 저-데이터 상황에서의 강건성은 추가 평가가 필요함.

## 개발자 관점

- 재현 핵심사항: 시각 인코더로 ImageNet 사전학습 ResNet-18 사용, 촉각 인코더는 ResNet-18을 처음부터 학습, 액션 오토인코더(Ea, Da) 구성 및 latent 차원 맞추기 필요. 흐름 속도장 v_theta는 경량 MLP로 구현. 학습 중 ODE로 생성된 잠재를 디코딩해 Lact를 적용해야 추론시 격차를 줄일 수 있음.
- 하이퍼·설정: 행동 청크 H=16, 매 재계획시 실행할 동작 수 h=8, 추론시 ODE explicit Euler 6 단계 사용(본 논문에서 이 설정으로 실시간 성능 달성). Diffusion 계열 대비 샘플 스텝 수(=추론 지연)에 민감하므로 경량 flow-matching은 저지연을 목표로 할 때 유리함.
- 배포·비용: 대형 사전학습 영상 백본을 사용하지 않아 GPU 메모리·연산비용이 상대적으로 낮아 엣지 혹은 온보드 배포 가능성이 높다(논문은 단일 RTX 4090에서 학습·평가 수행). 그러나 실제 제어 주파수는 센서/로봇 인터페이스에 의존하므로 통합시 엔드투엔드 병목(센서 드라이버, 통신 지연 등)을 점검해야 함.
- 안전성·운영: 모델은 접촉을 유지하면서 촉각에 기반한 보정 동작을 학습하므로 실물 배치 시 힘·토크 한계, 그리퍼·물체 손상 방지 등 물리적 안전 제약을 별도로 설계해야 함(저수준 안전 필터 권장).
- 구현 시 주의점: 잠재와 타겟의 차원 일치(flow 요구사항), 학습 중 ODE 통합을 통한 그래디언트 흐름(논문은 ODE 통합 과정에 그래디언트가 전파됨)을 처리할 수 있는 프레임워크/메모리 고려, multi-horizon 타겟 구성(시각 호라이즌 vs 촉각 next-frame)과 손실 가중치(λ들)의 민감도는 소거 실험에서 영향을 미침.

**근거 범위:** 이 분석은 제공된 논문 PDF 본문(페이지 1–8)의 텍스트를 근거로 작성되었음. 표와 그림의 수치(예: 표 I, II, III 및 본문 서술)는 PDF 본문에서 직접 추출·요약하였다. PDF에서 초록과 본문 일부 간에 추론 지연 수치(예: 초록의 11.9 ms vs 본문 표의 10.35±0.14 ms)와 같은 작은 불일치가 존재하므로 본문 표(표 III)의 값을 주된 근거로 사용했다. PDF 외부의 추가 구현 세부사항이나 미기재 수치(예: 정확한 잠재 차원, MLP 레이어 수 등)는 본문에 명시되지 않아 포함하지 않았다.
