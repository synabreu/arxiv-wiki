## 한 문장 요약

조건부 잠재 브리지 매칭(Latent Bridge Matching)을 사용해 단일 모델로 필드강도 및 모달리티 간 빠른 제어 가능한 뇌 MRI 합성을 수행한다.

## 해결하려는 문제

서로 다른 자기장 강도(0.1T–7T)에서 획득된 MRI는 노이즈, 해상도, 균질성 및 콘트라스트에서 큰 차이를 보여 다중 사이트 연구와 다운스트림 머신러닝 적용을 저해한다. 기존 고해상도 합성 방법은 고해상도 픽셀 공간에서의 브리지 매칭/확산 기반 연산이 비싸고, 다중 필드·모달리티를 단일 모델로 통합해 제어 가능하게 합성하는 효율적이고 빠른 방법이 부족하다.

## 핵심 기여

- 단일 통합 조건부 모델로 MRIxFields2026의 세 가지 과제(저→7T 합성, 0.1T→고장합성, 임의 필드간 제어합성)를 아키텍처·학습 변경 없이 해결.
- 잠재 공간(latent)에서 브리지 매칭을 수행하는 conditional latent bridge matching 파이프라인 설계(사전학습 VAE + 조건 인코더 + 경량 드리프트 네트워크).
- 단일 ODE/SDE 통합(실험상 1 스텝)을 이용한 매우 빠른 추론을 달성하여 30 축 방향 슬라이스의 모든 필드·모달리티 조합을 ≈90초 내(단일 NVIDIA A5000 GPU) 생성.
- Marigold 기반 UNet 드리프트 모델 초기화·확장과 필드강도(연속값)·타깃 모달리티를 교차어텐션에 주입하는 경량 조건 인코더 설계.
- 다양한 노이즈 σ, 시간 분포 τ(t), 네트워크 초기화 등에 대한 광범위한 절삭 실험(ablations)을 제공하여 설정의 민감도를 분석.

## 접근 방법

* 아키텍처: 사전학습된 Stable Diffusion v2.1 계열 VAE(sd-research/stable-diffusion-2-1-base)를 2D 축 슬라이스(Unpaired dataset, 1,900+ volumes)로 파인튜닝해 인코더 E와 디코더 D를 얻음.
* 인코더는 잠재 가우시안(µ,σ)을 예측해 재매개변수화로 latent z를 샘플링함(잠재는 4채널 그룹×4=16채널 입력 구조 사용).
* 드리프트 모델 vθ는 Marigold-Depth 기반 UNet(prs-eth/marigold-depth-v1-1)을 확장해 16채널 입력을 받도록 conv_in을 확장·복제 초기화(처음 4채널 가중치를 3배 복제 후 1/3 스케일 등)함.
* 조건 인코더: 입력 필드강도(ssrc), 목표 필드강도(stgt)는 [0,1]로 정규화 후 K=8짜리 사인·코사인 고정 인코딩으로 맵핑하고 학습된 선형 투사로 교차어텐션 컨텍스트(R=1024)로 보냄; 목표 모달리티는 임베딩 테이블을 통해 동일 공간으로 투사.
* 알고리즘(학습): 잠재 브리지 매칭 손실 LLBM(식(8))과 재구성·LPIPS·SSIM 항을 결합한 손실로 드리프트 모델을 학습.
* VAE는 unpaired 데이터로 λrec=0.5(L1), λKL=1e-6, λLPIPS=0.1, 25k steps, AdamW, 배치4(4 gradient accumulation), lr peak 3e-5, EMA β=0.9997, 학습 28시간(3×A10 GPU).
* 드리프트 모델은 paired dataset(작은, travelling-cohort 40 volumes 중 소수 훈련 샘플 사용)으로 학습: σ=0.001, 시간 스케줄 τ(t)=0.9δ0+0.025δ0.25+0.05δ0.5+0.025δ0.75, λrec=0.1(정규화 nRMSE), λSSIM=0.1, λLPIPS=0.2, AdamW, 배치2·16 gradient accumulation, warmup 500 steps 후 10,000 steps, lr vθ 3e-5, 조건 인코더 1.5e-4, ZeRO-1, mixed precision, EMA β=0.9995, 학습 40시간(3×A10).
* 추론: 입력으로 3개 소스 콘트라스트(T1,T2,T2FLAIR) 슬라이스(centre-crop 384×384)를 각각 VAE로 인코딩해 3×4채널=12채널 Zsrc 생성.
* 브리지 상태 Zt는 목표잠재 Z1이 없으므로 초기화시 Z0로 둠.
* 조건 임베딩(ssrc,mtgt,stgt)을 고정해 교차어텐션에 제공하고 latent SDE dZt = vθ(Zt,t) dt + σ dWt를 통합(실험상 1 스텝으로도 우수), 마지막 ˆZ1을 디코더로 복원 후 원래 해상도로 제로패딩.

## 주요 결과

- 데이터: 큰 unpaired 셋(1,900+ volumes)과 paired travelling-cohort(40 volumes: 3 train, 17 validation, 20 test) 사용(본문 설명).
- 검증(metrics, Table 1): Task 1(ultra-high-field 합성): SSIM=0.914, LPIPS=0.072, nRMSE=0.289, Dice=0.898, Volume=0.880.
- Task 2(higher-field from 0.1T): SSIM=0.885, LPIPS=0.092, nRMSE=0.202, Dice=0.857, Volume=0.839.
- Task 3(controllable field-to-field): SSIM=0.902, LPIPS=0.081, nRMSE=0.230 (Dice/Volume 미기재).
- 추론 속도(본문/초록): 단일 NVIDIA A5000에서 30 axial slices에 대해 모든 4×3(필드×모달리티) 조합을 ~90초 이내에 생성; 전체 볼륨의 교차-모달리티·강도 변환을 단일 GPU에서 70초 미만에 생성(초록 기술). 본문에서 최적설정(Marigold, σ=1e-3, τDW)으로 1 inference step에서 SSIM=0.9269 달성(절삭 연구).

## 한계

- 저자 명시 한계: 각 2D 축 슬라이스를 독립적으로 생성하므로 축간(inter-slice) 강도 일관성이 낮아 곧은 단층(밴딩) 아티팩트가 발생함. 이에 대한 완화책으로 세 축(3 orientations) 모두에서 생성 후 평균화하면 왜곡 계수(nRMSE 등)는 개선되나 LPIPS(지각적 유사도)는 악화하고 추론 시간이 3배 증가함(예: Task1 nRMSE 0.289→0.266, Task1 LPIPS 0.072→0.077 등 본문 수치).
- 저자·본문에 근거한 제약: 드리프트 모델은 소수의 paired 볼륨(논문 서술에 따르면 paired 세트에서 매우 작은 훈련 샘플 사용: 전체 paired 40개 중 3개가 훈련에 할당된 메타데이터)으로 학습되며, 이는 일반화 평가(특히 미지의 스캐너/코호트)에 제약이 있을 수 있음.
- 추론/검증 범위: 논문은 검증 리더보드(Validation) 성능을 보고하며(본문 Table 1), 공개된 테스트셋(20개)에 대한 최종 테스트 성능은 본문에 제시되어 있지 않음.
- 설계·재현성 관련 미확인 점(본문에 상세 명시 없음): 일부 전처리·데이터 증강 세부(예: paired 데이터의 구체적 샘플링/정규화·정렬 절차)와 테스트 단계의 정확한 하드웨어·배치·병렬화 조건 등은 본문에서 제한적으로 언급됨.

## 개발자 관점

- 재현성: 코드 리포지토리(초록·본문에 링크 명시)를 기반으로 VAE(sd-research/stable-diffusion-2-1-base) 파인튜닝 → Marigold 기반 UNet 확장 → 조건 인코더 추가 → latent bridge matching 손실로 드리프트 학습의 순서를 따름.
- 핵심 구현 포인트: conv_in 채널 확장 시 기존 가중치 복제·스케일링 방식(첫 4채널 가중치 3배 복제 후 1/3 스케일)으로 초기화하면 안정적; 필드강도는 연속값으로 처리해 사인·코사인 포지셔널 인코딩을 사용해 교차어텐션에 주입.
- 학습·리소스 비용: VAE 파인튜닝(25k steps)과 드리프트 모델 학습(10k steps)은 본문상 각각 28시간·40시간을 소요(각각 3×NVIDIA A10 GPU 사용). ZeRO-1, mixed precision, EMA 활용 권장.
- 추론·배포: 단일 스텝 통합으로 빠른 추론이 가능(A5000에서 30슬라이스·모든 조합 ≈90s). 볼륨 일관성이 중요하면 3축 생성·평균화 방법을 적용하되 추론시간이 3배 증가함을 고려해야 함.
- 안전성·임상 적용 주의: 합성 영상은 구조·콘트라스트를 향상시키지만 의료적 결정에 사용하기 전 철저한 임상 검증 필요. 합성에서 발생하는 아티팩트(특히 슬라이스 간 불연속)는 자동 분석(분할·측정)에 영향을 줄 수 있음.
