## 한 문장 요약

생성형 LLM의 '편향(bias) 헤드'를 찾는 기존 head-level ablation 파이프라인을 Qwen-2.5-7B-Instruct와 Llama-3.1-8B-Instruct에서 재현·검증하여, 선택 통계가 실제로는 응답 길이·프롬프트 정체성 등으로 오염되어 '무엇을 측정하는가'가 비식별적임을 실험적 개입으로 보여줌.

## 해결하려는 문제

기존 연구들은 개별 어텐션 헤드 단위로 사회적 편향을 국소화하고 해당 헤드를 제거하면 공정성 지표가 개선되는지를 근거로 방법을 정당화하지만, '어떤 통계가 헤드를 선택하는가'에 대한 구성 타당성(construct validity) 검증이 부족하다. 특히 생성 응답을 판정자(label)에 따라 분할해 통계를 계산하는 설계는 응답 길이 등 표면 상의 공변량과 강하게 결합되어 있어 관찰적 분석만으로는 통계가 편향을 측정하는지 분리할 수 없다는 문제가 제기된다.

## 핵심 기여

- 응답 길이(라벨 맹시)로 만든 통제 맵이 원래의 공정성 맵과 Qwen에서 ρ = −0.950, Llama에서 −0.768로 강하게 상관함을 재현하고, 추가 상관적 통제가 모두 동일한 잘못된 해석을 지지함(Sections 4.3, B.11).
- 길이-라벨 결합을 깨는 개입(간결/장문 프롬프트)을 통해 길이 가설을 실험적으로 기각: 동일 프롬프트 내에서는 길이가 통계 분산의 1%만 설명하고 대신 프롬프트 정체성이 64%의 분산을 설명함(Section 4.4, B.15).
- 원본 방법의 실질적 주장(편향 헤드가 후기층에 집중, 해당 헤드들을 제거하면 불공정률 감소)이 복제되지 않음을 정량적으로 제시: 대다수 설정에서 선택된 헤드들은 후기층 집중을 보이지 않으며(centre-of-mass 통계), 우리가 테스트한 어떤 prescribed head set도 불공정률을 낮추지 못함(Sections 4.5–4.6, B.14).
- 양성 대조(positive control)으로 prescribed set의 '역집합'(opposite-label top-K)을 사용했을 때 일관되게 거절(refusal) 행동을 파괴하는 효과를 재현하여 파이프라인이 이 규모의 효과는 검출할 수 있음을 보임(저장/재선택 합병 Fisher p = 2.7×10−5 / 1.75×10−5, Section 4.6.2).
- 실천적 계측·검증 위험을 정리: (i) 단일 랜덤 baseline이 넓은 null band(예: Qwen 0.641–1.000, Llama 0.603–0.886) 안에 들어 무의미함, (ii) ablation으로 생성 품질이 손상되면 손상된 출력을 'fair'로 점수화해 실패를 성공처럼 보이게 할 수 있음(Section 4.6–4.7, A.2).

## 접근 방법

* 원본 DiffHeads 계열의 대비(head-level contrastive) 절차를 재현: DA(Direct-Answer)와 CoT(Chain-of-Thought) 등 두 프롬프트 스타일로 응답을 유도하고(식별: 60문항×스타일, 평가: 균형잡힌 80문항), 각 응답을 규칙 기반 라벨러로 fair/unfair/unclassifiable로 분류한 뒤 각 헤드별 점수 S(l)_h = (1/\|R\|) Σ_{r∈R} [h W_O,h z_{r,h}^{(l)}]^⊤  v_ref+ 를 라벨 별로 계산하고 층별 표준화하여 순위를 매김(두 reference-reading: final-layer 및 layer-matched을 구현해 검증).
* 선택 규칙은 K=20로 상위 K를 취해 H_diff = TK(S_unfair) \ TK(S_fair)로 prescribed set(대개 10개 헤드)를 구성하고, 해당 헤드를 o_proj의 입력 슬라이스를 0으로 마스킹(마스크는 디코딩 전 next-token KL(base \|\| masked) > 1e-4 및 다른 greedy 텍스트 조건을 확인함).
* 평가: 주 결과는 unfair/(unfair+fair) 비율(언클래시파이블은 별도 보고)이며, split-half 신뢰도, 라벨-치환(placebo), 다(5)-신호 degeneracy 스크린, 층-매칭 랜덤 10드로우 null band 등을 사용.

## 주요 결과

- 행동적 전제(DA vs CoT 불공정률 격차)는 재현됨: Qwen DA 0.800 vs CoT 0.225(간극 0.575), Llama 0.778 vs 0.167(간극 0.611) (Section 4.2, B.18, Table 13).
- 응답 길이 맹시(control length map)와 공정성 맵의 상관: Qwen ρ = −0.950, Llama ρ = −0.768; 상위 10개 헤드 중 각각 9/8개가 길이에 의해 억압되는(heads most length-suppressed) 것으로 겹침(Section 4.3, Table 10).
- 길이 개입 실험(DA, CoT, verbose, terse): 전체 병합 시 길이-점수 상관 ρ = −0.758(p = 2.3×10−42)처럼 보이나, 단일 프롬프트(특히 terse) 내에서는 길이가 설명력 없음 — terse에서 응답 평균 10.1 token, 길이와 점수 상관 ρ = −0.025(p = 0.85)로 길이가 점수 분산의 1%만 설명하고, 대신 라벨과의 상관은 +0.690(p = 1.1×10−9). 전체 분산의 64%는 프롬프트(arm) 정체성이 설명(Section 4.4, B.15, Table 2).
- 층 분포: layer-matched reference에서 bias selectivity는 두 모델 모두에서 우연보다 '더 이른 층'에 집중됨(예: Qwen centre-of-mass 11.72 vs null 13.5, p = 0.011; Llama 13.67 vs 15.5, p = 0.021). 8개의 model×reference×labeller 조합 중 7개가 우선적으로 '이른 층' 배치를 보였고 어떤 경우에도 원문이 주장한 '후기층 집중'은 관찰되지 않음(Section 4.5, B.14, Table 12).
- 인과 평가(평가셋 80문항, 각 모델별 13개 암 포함): prescribed set는 대부분 경우 불공정률을 줄이지 못함 — 예: 저장된 Qwen set 마스킹 ∆ = +0.013(비의미), Llama final-layer 저장선택은 31% unclassifiable을 유발해 apparent ∆ = −0.127(생성 붕괴에 의한 'breakage')으로 제외됨(Section 4.6.1, Table 3). 반면 complement set(반대 라벨에서 top-K로 선정된 집합)은 저장·재선택 모두에서 일관되게 거절 행동을 파괴(저장 결합 Fisher χ2 p = 2.7×10−5, 재선택 합병 p = 1.75×10−5)하여 파이프라인이 이러한 규모의 효과를 검출할 수 있음을 보임(Section 4.6.2, Table 4). 랜덤 층-매칭 10드로우 null band는 Qwen 0.641–1.000, Llama 0.603–0.886로 넓어 단일 랜덤 제어는 무의미함(Section 4.6.3, A.3).

## 한계

- 저자가 명시한 한계 — 데이터 규모와 도구: 식별(identification) 세트는 60문항(원본 2,516)으로 축소되었고, 라벨링은 논문 저자(단일 주석자)의 규칙 기반 라벨러를 사용해 LLM 판정자와 다른 점이 있음(Section 'Limitations').
- 저자가 명시한 한계 — 일반화: 길이 개입은 생성·판정 방식의 한 하위군(생성 응답을 판정자 라벨로 분할하는 설계)에 대해서만 실험되었고, minimal-pair 계열(응답형을 고정하는 설계)에는 적용되지 않음(Section 'Limitations', 5.3).
- 저자가 명시한 한계 — 사양 불명확성 및 구현 차이: 원문이 reference vector ¯vref, 평균 집합 R, k 등 일부를 불명확하게 기술해 두 가지 reference 읽기(final-layer, layer-matched)를 구현·보고함; 다른 구현이 다른 랭킹을 반환할 가능성 있음(Section 3.2, B.9, 'Specification and implementation').
- 연구 범위에서 드러나는 제약 — 라벨·그룹토큰·길이의 다중공선성: 단일 프롬프트 내에서는 fairness 라벨, 응답 길이, 보호집단 토큰 존재가 강하게(collinear, ϕ = 0.951) 묶여 있어 관찰적 데이터만으로는 어떤 변수가 헤드 점수를 유발하는지 분리 불가능함(Sections 4.4, 5.1, B.15). 이는 라벨 규칙의 정의적 부분 때문이기도 함(라벨러가 불공정 판정 시 그룹명 매칭에 의존).  

추가 실험적·방법론적 한계: CoT 팔(체인오브생각)에서 unclassifiable 비율이 높아(CoT에서 20/60, 24/60) CoT 관련 분석이 표본 부족으로 제약됨(Section 'Limitations'). 마스킹·계측 구현 검증은 코드-대-코드 교차 재구현하지 않았음(Verification not performed).

## 개발자 관점

- 관찰적 상관(예: 헤드 맵 vs 응답 길이)만으로는 기계적 원인(편향 인코딩)을 확정할 수 없으므로 명시적 대안 가설(예: 길이 맵)로부터 만든 통제 맵(control map)을 항상 보고해야 함(Sections 4.3–4.4, 5.3).
- 인과적 개입(예: 프롬프트로 길이·형태 조작) 없이는 통계의 측정 대상을 식별할 수 없으므로, 적어도 하나의 개입 실험을 설계해 '결합(breaking the coupling)'을 검증할 것(Section 4.4, 5.3).
- 랜덤 null은 여러 드로우(권장 ≥10)로 층-매칭한 밴드를 제시해야 함—단일 랜덤 드로우는 넓은 null band 안 어디에나 위치할 수 있어 오해의 소지가 큼(Section 4.6.3, A.3).
- 마스킹(헤드 제로잉)로 생성 품질이 손상되면 손상된 출력을 'fair'로 점수화할 수 있으므로 평가 분모 규칙(언클래시파이블을 포함할지 제외할지)을 명시하고, 생성 품질(degeneration) 스크린(예: 반복 토큰, 낮은 어휘다양성, prompt-echo 등)을 평가셋에서 실행할 것(Sections 4.6–4.7, B.13, A.2).
- 재현을 위해 원본 논문이 불명확하게 적은 설정(¯vref의 공간, 평균 집합, K 값 등)을 문서화하고, 선택·마스킹·검증 절차의 구현을 독립 재검증(코드 교차검증)할 것(Sections 3.2, B.9, B.8). 또한 라벨러를 외부 주석자와 교차검증하고 라벨러의 읽기 윈도(예: 250 char)를 결과에 미치는 영향도 보고할 것(Section 3.1, B.12).

**근거 범위:** 이 분석은 제공된 논문 PDF 본문(메인 텍스트 및 부록 포함)을 근거로 작성되었음. 본문에서 명시적으로 나타난 수치(p-values, 상관계수, 비율 등)와 저자의 한계·방법 기술을 그대로 인용·요약했다. 원문이 불명확하게 기술한 요소(예: reference vector의 정확한 정의, 원저자의 내부 구현 세부)는 저자가 언급한 대로 두 가지 읽기를 재현한 결과로 기술했으며, 코드-대-코드 독립 재구현 여부는 본문에서 수행되지 않았다고 명시되어 있어 그 점은 확인되지 않음.
