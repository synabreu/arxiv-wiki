## 한 문장 요약

멀티모달 MoE 내부에서 자연스럽게 형성되는 전문가(專門家) 분해능을 라우터 가중치에서 해독해(domain) 관련 전문가만 선택적으로 미세조정하여 데이터 없이 효율적으로 도메인 적응을 수행하는 방법(ExpertLens)을 제안하고 실험적으로 검증했다.

## 해결하려는 문제

대형 멀티모달 Mixture-of-Experts(MoE) 모델은 희소 라우팅으로 계산 효율을 얻지만, 특정 도메인으로 신속하고 비용효율적으로 적응하려면 어느 전문가들이 해당 도메인에 특화되어 있는지 알아야 한다. 기존의 파라미터-효율적 적응(예: LoRA)은 보통 새로운 적응 파라미터를 도입하거나 전체 모델을 미세조정해야 하며, 도메인별 전문가를 데이터 없이 식별해 선택적으로 미세조정하는 실용적 방법이 부족했다.

## 핵심 기여

- 멀티모달 MoE에서 모달리티(이미지/텍스트), 도메인(의료·수학·원격탐사) 및 세부 객체 의미 수준에서의 자발적(비강제적) 전문가 전문화(emergent specialization)를 실험적으로 규명함.
- 라우터 가중치를 LM head로 투영해 각 전문가의 상위 어휘 토큰을 복원하고 이를 도메인 관련성으로 분류하는 데이터-프리 방법 ExpertLens를 제안함(토큰 M=10, 선택기준 SEL≥0.9).
- ExpertLens로 도메인 관련 전문가만 선택적으로 미세조정하면 전체 미세조정(FFT)과 동등하거나 우수한 적응 성능을 유지하면서 21.7–47.0%의 파라미터만 갱신하고 평균 4.0× 학습 속도 향상을 달성함. LoRA보다 성능과 학습 효율 모두 우수함을 보임.
- 라우팅·전달체계(router·decoder) 파라미터를 함께 갱신해야 선택적 전문가 미세조정이 효과적임을 규명하고, 무작위 선택·빈도 기반 선택·특권 오라클과 비교한 다양한 분석 및 레이어·모델별 검증을 수행함.

## 접근 방법

* 핵심 아이디어(ExpertLens): 라우터의 전문가별 행(전문가 라우터 가중치 w^{(ℓ)}_i)을 모델의 언어모델(LM) 헤드 U를 통해 투영하여 어휘-로짓 z^{(ℓ)}_i = U w^{(ℓ)}_i 를 얻고, 상위 M(=10) 토큰 V^{(ℓ,i)}_M 을 복원한 뒤 각 토큰이 목표 도메인 d와 관련 있는지(Rel(v,d), {0,1})를 판정해 전문가-도메인 친화도 SEL^{(ℓ,i)}_{EL}(d)= (1/M) sum_v Rel(v,d)을 계산한다(토큰 분류는 프롬프트 기반의 결정적 분류, 본문 §A.3·프롬프트 수록).
* SEL≥0.9를 만족하는 전문가들을 도메인 관련 전문가 코호트로 선정한다.선택적 적응(Selective adaptation): 선정된 전문가 MLP들만 미세조정하고(나머지 전문가 MLP은 동결), 동시에 공유 디코더 파라미터(라우터 가중치, QKV 투영, LM head 등)는 함께 학습한다(본실험 구성).
* 적응 프로토콜은 연속적 시퀀셜 적응으로 단일 사전학습 모델을 순차적으로 수학→의료→원격탐사(또는 다른 순서)로 4,000 샘플/도메인, 각 도메인당 200 스텝 학습, GSPO 보상, VERO 시스템 프롬프트를 사용한다.
* 구현·학습 세부: QWEN3-VL-30B-A3B(주), KIMI-VL-A3B·GEMMA-4 26B-A4B 검증, 4×H200 GPU, 배치 32, group size 5, lr=1e-5, bfloat16, 세드 3회(신뢰구간 표기).

## 주요 결과

- ExpertLens는 전체 미세조정(FFT)과 동등하거나 다소 우수한 최종 성능을 달성하면서 모델 파라미터의 21.7–47.0%만 갱신함(즉 53.0–78.3%는 동결).
- 도메인별 최종 정확도(순차 적응 실험, QWEN3-VL-30B-A3B): ExpertLens는 수학 64.6% vs FFT 63.8% vs LoRA 55.8%; 의료 53.7% vs FFT 53.6% vs LoRA 52.0%; 원격탐사 51.9% vs FFT 51.6% vs LoRA 49.4%(본문 Fig.6A).
- 학습 시간(벽시계) 비교: ExpertLens는 FFT 대비 도메인별 속도향상 3.2×(수학), 4.0×(의료), 4.8×(원격탐사), 평균 4.0×; LoRA 대비 평균 2.9× 더 빠름(본문 Fig.6B).
- 전문가 선택 스케일(예: QWEN3 기준): SEL≥0.9일 때 선택된 전문가 수는 수학 2,768, 의료 1,103, 원격탐사 1,290(§A.3·Fig.8).
- 무작위(동일 예산) 선택 대비 우위: 동일 예산의 Random(full)·Random(disjoint) 대비 ExpertLens가 일관되게 더 높은 성능을 보였음(Fig.7). 또한 공유 디코더 파라미터를 함께 갱신하는 것이 중요하며(라우터 추가 시 수학 성능 +11.2점, Table 2), 라우팅 구조는 학습 전후에 고도로 보존되어(최종 체크포인트가 사전학습 라우터와 약 90% 이상 top-8 전문가 집합 겹침) 안정적임. 또한 KIMI-VL-A3B에서의 반복 실험에서도 평균 성능(ExpertLens 48.0% vs FFT 47.4% vs Random 45.0%)으로 유사한 이득을 보였음(Table 4).

## 한계

- 저자가 명시한 한계 — ExpertLens의 토큰-레벨 분류 노이즈: 라우터-가중치로부터 복원한 상위 어휘 토큰에 불완전·중의적(서브워드 조각, 구두점, 다국어 단편, 제어 토큰) 항목이 포함되어 있고, 이들을 도메인 관련으로 잘못 분류하면 전문가 라벨링에 잡음이 유입됨(§A.3, Table5).
- 저자가 언급한 범위 제한: 실험은 수학·의료·원격탐사 세 도메인과 세 개의 대형 MoE 기반 VLM(QWEN3-VL-30B-A3B 주실험, KIMI-VL-A3B·GEMMA-4 보조검증)에 국한됨. 다른 도메인·작은 모델·다른 사전학습 정책에서 동일한 이득이 그대로 재현될지는 보장되지 않음.
- 본문에서 합리적으로 확인되는 추가 제약(저자와 구분): ExpertLens는 라우터 가중치·LM head에 접근 가능해야 하며(데이터-프리이지만 내부 가중치 접근 필요), LM head를 이용한 토큰 분류에 의존하므로 사전학습된 LM head의 언어·도메인 분류 능력에 영향을 받음. 또한 실험은 각 도메인당 4,000 샘플·200 스텝이라는 제한된 적응 예산 하에서 수행되었으므로 대규모·장기간 적응 시 거동은 추가 검증이 필요함.

## 개발자 관점

- 필요조건: 모델의 라우터 행(각 전문가의 라우터 가중치)과 LM head(토큰 로짓 매핑)에 접근해야 ExpertLens를 적용할 수 있다.
- ExpertLens 적용 절차: (1) 각 전문가 라우터 행을 LM head로 투영해 상위 M=10 토큰 추출, (2) 토큰을 도메인 관련성으로 프롬프트 분류(논문에 수록된 JSON 프롬프트 사용), (3) SEL≥0.9 등 임계값으로 전문가 코호트 선택, (4) 선택 전문가 MLP만 동적 학습하고 라우터·QKV·LM head 같은 공유 디코더 파라미터는 함께 학습해야 최적 성능을 얻음(ablations, Table2).
- 재현·하이퍼파라미터: 논문 기본 실험은 GSPO 보상·VERO 시스템 프롬프트·4,000 샘플/도메인·200 스텝/도메인·4 H200 GPU·배치32·lr=1e-5·bfloat16로 실행됨(§A.5·Table7). 동일 셋업을 우선 모사할 것.
- 성능 vs 비용: 선택적 전문가만 갱신하면 파라미터·학습시간 절감(21.7–47.0% 파라미터 갱신, 평균 4.0× 학습 가속)을 얻을 수 있으므로 실제 배포 환경에서 비용-성능 트레이드오프에 유용함.
- 안정성 및 검증: ExpertLens 선택이 무작위보다 일관되게 우수하나(동일 예산 대비), 도메인과 모델이 바뀌면 SEL 임계값·토큰 분류 프롬프트·M 값 등을 검증·조정해야 함. 토큰 분류의 잡음을 줄이기 위해 후속 검증 데이터(소량)를 활용한 정제(fine-grained filtering)를 고려할 수 있음.
