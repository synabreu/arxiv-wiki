## 한 문장 요약

Mixture-of-Experts(VLM)의 내부 라우팅 확률만으로 대상 객체 부재(타깃-부재) 여부를 사전 탐지하고, 선별적 리그라운딩(리뷰 프롬프트)으로 응답 오류를 줄이는 경량 검출·개입 프레임워크를 제안한다.

## 해결하려는 문제

비전-언어 모델(VLM)이 질문 대상 객체가 이미지에 없는데도 그 객체의 색·수·위치·상태 등에 관해 답하는 '타깃-부재(target-absence) 그라운딩 실패'가 발생한다. 기존 시도들은 주로 모델의 생성물(생성 응답), 은닉 상태 또는 불확실도 측정치를 이용해 이러한 실패를 감지하려 했으나, 사전 생성 단계에서 정확하고 저비용으로 실패를 감지해 선택적으로 개입하는 방법은 제한적이다. 연구 질문은 MoE(VLM) 내부의 토큰별 라우팅 결정이 타깃의 부재를 검출하는 데 충분한 신호를 보존하는지, 그리고 이를 이용해 가중치 수정 없이 선택적 리뷰로 엔드투엔드 성능을 개선할 수 있는지이다.

## 핵심 기여

- MoE 기반 VLM의 내부 라우팅 결정(routing probabilities)을 최초로 활용해 타깃-부재를 생성 이전에 감지하고 선택적 리그라운딩을 유도하는 프레임워크를 제안함.
- Qwen3-VL-30B-A3B-Instruct와 Gemma-4-26B-A4B-it의 타깃-토큰 라우팅 확률을 추출하고, 각 모델별로 L2 정규화 선형 검출기를 학습시켜 간단한 검출기를 구축함.
- 라우팅 신호만으로 GQA-Inpaint에서 매우 높은 ROC-AUC(각각 0.9988, 0.9956)를 달성하고, 외부 데이터셋 OBER에서도 상당한 보존 성능(각각 0.8095, 0.7781)을 보였음을 실험적으로 입증함.
- 검출기 예측에 따라 대상-인식(타깃-어웨어) 리뷰 프롬프트를 선택적으로 호출하는 라우팅-게이티드 정책으로 모델 가중치 변경 없이 엔드투엔드 정확도를 크게 향상시킴(예: Qwen에서 GQA-Inpaint +22.25%, OBER +12.17%).
- 라우팅 신호가 타깃 객체 토큰에 국한되어 나타나고, MoE의 초기 레이어에서 등장하며, 부분적으로 대체 가능한(experts에 분포된) 특성을 가진다는 분석적 관찰을 제공함.

## 접근 방법

* 입력 이미지와 질의가 주어지면, 대상(타깃) 관련 토큰의 라우팅 확률(routing probabilities)을 MoE VLM 내부에서 추출한다.
* 대상-토큰별 라우팅 벡터를 특징으로 사용하여 각 모델(Qwen3-VL-30B-A3B-Instruct, Gemma-4-26B-A4B-it)에 대해 L2 정규화(linear with L2 regularization)된 선형 검출기를 학습한다.
* 추론 시 검출기가 타깃-부재 가능성을 예측하면, 해당 예측을 임계값 기준으로 게이트로 사용해 '타깃-어웨어 리뷰 프롬프트'를 선택적으로 호출(리그라운딩)한다.
* 이 절차는 모델의 가중치를 변경하지 않으며, 라우팅 정보만으로 사전(생성 이전) 판단을 수행함.
* 본문 분석에서 라우팅 신호는 타깃-토큰에 국한되어 있고 초기 MoE 레이어에서 뚜렷하며, 여러 전문가(experts)에 분산되어 나타난다고 보고한다.

## 주요 결과

- 데이터셋: GQA-Inpaint, 외부 검증 데이터셋 OBER.
- 라우팅 기반 검출기 성능(GQA-Inpaint ROC-AUC): Qwen 0.9988, Gemma 0.9956.
- 외부 데이터셋 성능 유지(OBER ROC-AUC): Qwen 0.8095, Gemma 0.7781.
- 라우팅-게이티드 정책의 엔드투엔드 정확도 개선(가중치 수정 없음): Qwen — GQA-Inpaint +22.25%, OBER +12.17%; Gemma — GQA-Inpaint +13.42%, OBER +1.39%.
- 추가 관찰: 임계값이 데이터셋 간에 이동(shift)하여 재캘리브레이션이 필요하며, 잘못된 양성(false-positive)으로 인한 리뷰 호출이 전체 성능에 끼치는 피해는 제한적이라고 보고됨.

## 한계

- 저자가 명시한 한계: 데이터셋 간 임계값(검출기 기준)의 이동이 있어 교차-데이터셋 적용에는 재캘리브레이션이 필요하다는 점. 또한 잘못된 양성 리뷰의 위험은 제한적이지만 완전히 무해하지는 않음.
- 본문 실험 범위에서 확인되는 제약(추론된 한계): 방법은 MoE 아키텍처의 내부 라우팅 접근이 가능한 모델에만 적용 가능하며, 실험은 두 개의 특정 MoE VLM(Qwen3, Gemma)과 두 개의 데이터셋(GQA-Inpaint, OBER)에 한정되어 있어 다른 모델군·도메인 일반화는 추가 검증이 필요함. 또한 세부적인 구현(예: 사용한 레이어 인덱스, 정확한 프롬프트 문안, 검출기 학습 데이터·하이퍼파라미터)의 구체적 값은 본문에서 상세히 제시되지 않은 경우 재현 시 추가 정보가 요구된다.

## 개발자 관점

- 실행 가능성: MoE VLM에서 이미 계산되는 라우팅 확률을 사용하므로 별도 대규모 추가 추론 비용 없이 경량 검출기(선형+L2)로 사전 검출을 구현할 수 있다.
- 필수 접근성: 라우팅 확률을 추출하려면 모델 내부 라우터에 접근·계측할 수 있어야 하므로 상용 API/폐쇄형 모델에서는 적용 제한이 있을 수 있다.
- 재현·하이퍼파라미터: 각 모델별로 별도의 선형 검출기를 학습하고 데이터셋별 임계값 재캘리브레이션이 필요하므로, 배포 전 운영 데이터에 대한 검정·보정 절차를 마련해야 한다.
- 운영·안전성: 잘못된 양성에 의한 불필요한 리뷰 호출이 전체 성능에 끼치는 악영향은 제한적이라고 보고되므로, 검출 임계값과 리뷰 프롬프트 설계를 함께 조절하면 개입 위험을 관리할 수 있다.
- 비용·배포 관점: 모델 가중치 변경이나 추가 거대한 모델 학습 없이 성능 개선이 가능해 경제적이며, 라우팅 신호의 조기(layer-초기) 출현 특성은 빠른 사전 판정 지점 선정에 유리하다.
