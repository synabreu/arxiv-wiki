## 한 문장 요약

언어모델 구성요소의 소거(ablation)가 유발하는 '자가복구(self-repair)' 현상은 여러 구성요소의 고정된 기울기(γ_r)를 갖는 아핀 법칙 E_r(λ)=own_r+γ_rλ으로 설명할 수 있으며, 이는 다양한 모델과 유닛 유형에서 재현되고 기울기 크기를 고정 가중치로부터 예측할 수 있음을 보인다.

## 해결하려는 문제

기존 관찰에서 언어모델의 일부분을 제거하면 다른 구성요소들이 보상하는 듯한 '자가복구' 현상이 반복적으로 관찰되었으나, 그 메커니즘은 불명확하다. 가장 체계적인 선행연구는 자가복구가 노이즈가 많고 단일한 설명을 기대하기 어렵다고 결론내렸는데, 기존의 표준적 ablation은 어떤 '강도'로 개입했는지 보정(calibration)되지 않은 단일 점으로 취급한다는 한계가 있다. 연구 질문은 (1) 자가복구의 통일적인 기계적 설명이 존재하는가, (2) 제거된 신호에 대해 다른 구성요소들의 반응을 예측·계량화할 수 있는가이다.

## 핵심 기여

- 자가복구 현상을 '개입 강도' λ라는 단일 차원(대조의 부호화된 세기) 위의 점으로 보고, 전통적 ablation을 보정되지 않은 λ 값으로 재해석하는 관점을 제시함.
- 개별 하위 유닛 r의 수식화된 응답 모델 E_r(λ)=own_r+γ_rλ(아핀 법칙)를 제안하고, γ_r(기울기)가 고정된 계수로서 개입 전후에 일관된 영향력을 가짐을 주장함.
- MLP 뉴런, OV(출력-가중치) 뉴런, 특이(singular) 방향 등 다양한 구성요소에 대해 아핀 법칙이 성립함을 실험적으로 확인(다중 모델에서 81개 하류 방향 중 68개가 법칙을 따름).
- 고정된 가중치로부터 γ_r의 크기를 예측할 수 있음을 보여주어 이 기울기가 단순한 실험적 잔재가 아니라 모델의 구조적 속성임을 시사함.
- GPT-2 Small의 IOI 회로 분석에서 개입이 도달 가능한 10개 헤드 중 7개가 아핀 법칙을 따르고 이들 모두가 '카운터웨이트(counterweight)'로 작동함을 보임.

## 접근 방법

* 저자들은 개입을 단일 스칼라 좌표 λ(대조의 부호화된 세기)로 파라메터화하여, 특정 구성요소를 제거(ablation) 또는 다른 강도로 개입할 때 하위 유닛 r의 응답 E_r(λ)을 관찰했다.
* 그 결과를 선형·절편 형태의 아핀 함수 E_r(λ)=own_r+γ_rλ로 모델링하여 각 유닛의 절편 own_r과 기울기 γ_r을 추정하였다.
* 실험적으로는 사실검증(factual-verdict) 과제를 여러 모델(Gemma, Qwen, LLaMA, Mistral)에서 수행하고, 분석 대상 구성요소로 MLP 뉴런, OV 뉴런, 특이 방향(singular directions)을 포함시켰다.
* 추가로 GPT-2 Small의 IOI 회로를 대상으로 헤드 수준에서 개입 가능성(reachability)을 고려해 동일한 분석을 적용했다.
* 마지막으로 추정된 γ_r 값을 모델의 고정된 가중치로부터 예측하는 실험을 수행했다.
* (구체적 데이터셋, 하이퍼파라미터, 적합 방법 등 본문 전체는 제공되지 않아 여기서 서술된 것은 논문의 핵심적 방법론 개요이다.)

## 주요 결과

- 제안한 아핀 법칙 E_r(λ)=own_r+γ_rλ이 여러 구성요소에서 관찰되었으며, 네 종류 모델(Gemma, Qwen, LLaMA, Mistral)에서 점검한 81개의 하류 방향 중 68개(=68/81)가 아핀 법칙을 따름.
- γ_r의 부호가 해당 유닛이 제거된 신호를 '카운터(상쇄)'하는지 또는 '강화'하는지를 결정함. 즉 부호로 유닛의 역할(반작용 vs. 보강)을 판별할 수 있음.
- 고정된 가중치로부터 γ_r의 크기를 예상할 수 있어 기울기가 모델 내 구조적 속성과 연관됨을 실험적으로 시사함(정량적 예측 가능성 주장).
- GPT-2 Small의 IOI 회로 실험에서 개입이 도달 가능한 10개 헤드 중 7개가 아핀 법칙을 따랐고(7/10), 이들 7개 헤드는 모두 제거된 신호를 상쇄하는 '카운터웨이트' 역할을 함.

## 한계

- 저자가 본문에서 직접 언급한 한계: 제공된 본문 발췌(초록)에는 저자가 명시한 제한사항이나 일반화 경계가 포함되어 있지 않음(원문 전체 접근 불가).
- 본문 근거로 합리적으로 확인되는 한계: 분석은 주로 '사실 검증(factual-verdict) 과제'와 GPT-2 Small의 IOI 회로 등 특정 태스크·회로에 대해 수행되어 범용성(다른 과제·대형 모델 행동 등)에 대한 일반화가 제한될 수 있음.
- 관찰된 아핀 법칙은 실험한 구성요소(MLP 뉴런, OV 뉴런, 특정 특이 방향)에 대해 보고된 것으로, 모델의 모든 종류의 유닛·회로·행동에 보편적으로 적용된다고 단정하기 어렵다.
- 제안된 분석은 내부 접근(활성화·가중치·직접 개입)을 전제로 하므로, API 수준에서의 모델 제어·평가에는 적용하기 어렵고 재현을 위해선 내부 가중치 접근 권한과 계산 자원이 필요함.

## 개발자 관점

- 재현성: 논문을 재현하려면 모델 내부(활성화·가중치)에 접근해 다양한 강도 λ로 정교한 counterfactual 개입을 할 수 있어야 하며, 각 유닛의 응답을 수집하고 아핀(선형+절편) 적합을 수행하는 파이프라인이 필요하다.
- 구현·계산비용: 다중 모델(예: Gemma, Qwen, LLaMA, Mistral)과 다수 유닛·방향을 검사하려면 대규모 활성화 수집과 선형 적합이 필요하므로 메모리·계산비용을 고려해야 한다.
- 측정·해석상 유의점: 전통적 ablation만으로는 '자가복구' 해석이 오도될 수 있으므로, ablation을 할 때는 개입 강도 λ를 다양하게 스윕해 응답 곡선을 확인하고 아핀 근사를 검증해야 한다.
- 배포·안전성: 단순 ablation으로 모델의 특정 행동을 제거하려고 할 때 내부의 카운터웨이트가 해당 행동을 유지할 수 있으므로, 모델 능력 제한이나 안전 조치로 ablation을 의존하는 것은 위험하다.
- 도구적 시사점: γ_r을 고정 가중치로부터 예측할 수 있다는 결과는 자동화된 진단·취약성 분석(어떤 유닛이 어떤 신호를 상쇄하는지 예측)을 가능하게 하여 해석 도구 개발에 유용하다.
