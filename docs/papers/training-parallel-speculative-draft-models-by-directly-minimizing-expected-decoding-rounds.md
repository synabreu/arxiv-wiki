## 한 문장 요약

평행·반자율(sem i-AR) 드래프터의 교차-라운드 의존성을 명시적으로 모델링해 '기대 디코딩 라운드(EDR)'를 도입하고, 이를 최소화하는 정확한 TD 형태의 그래디언트로 드래프터를 학습하여 검증(verification) 라운드 수를 직접 줄이는 방법을 제안한다.

## 해결하려는 문제

평행(parallel)·반자율(semi-AR) 드래프터는 한 번의 포워드로 블록 전체를 제안해 드래프팅 비용을 줄이지만, 같은 출력 위치에 대한 드래프트 분포가 라운드 시작점(n)에 따라 달라 라운드 간(교차-라운드) 의존성이 발생한다. 기존의 블록-로컬 학습 목적들은 이 교차-라운드 결합을 무시하는 근사(heuristic) 가중치를 사용해 전체 디코딩 효율(검증 라운드 수의 기댓값)을 직접 최적화하지 못한다. 연구 질문은 평행·반자율 드래프터를 '기대 디코딩 라운드'를 직접 최소화하도록 학습할 수 있는가이다.

## 핵심 기여

- 평행·반자율 드래프팅 과정을 목표 출력에 대해 조건화하면 마르코프 보상 과정(Markov Reward Process, MRP)으로 정확히 기술할 수 있음을 보이고 이를 통해 디코딩 라운드 수의 정확한 표현을 도출함.
- Expected Decoding Rounds(EDR) 목표함수를 도입하여 이를 최소화하는 것이 전체 기대 디코딩 라운드 수를 정확히 최소화함을 증명(Thm.1)함.
- EDR의 정확한 일-스텝 시간차(temporal-difference, TD) 형태 그래디언트를 유도해 타깃 모델 롤아웃만으로 편향 없는 확률적 최적화가 가능함을 보임(Thm.2)과, 학습에 효율적인 TD 형태 손실을 제시함.
- 타깃 모델 롤아웃만으로 드래프터별 기대 라운드 수와 위치별 수락률을 정확히 계산하는 오프라인 평가자(off-line evaluator)를 제공해 동일 롤아웃에서 드래프터를 쌍비교할 수 있게 함.
- 두 공개 SOTA 반자율 드래프터(DSpark, DFly)를 EDR로 한 에폭 파인튜닝한 결과, 아홉 개 벤치마크(수학·코드·챗)에서 평균 수락 길이(MAL)가 일관되게 개선됨을 실험적으로 보임.

## 접근 방법

* 방법의 핵심은 다음과 같다.
* (1) 타깃 모델이 생성한 출력 시퀀스 x를 고정한 조건부에서, 상태를 (라운드 시작 인덱스 n, 현재 검증 위치 t)로 둔 마르코프 체인을 정의하고, 각 상태의 '점유도(occupancy)' ω^{q}_{n,t}(x<t)와 상태에서의 거부 확률(또는 비용) R^{q}_{n,t}을 유도한다.
* (2) 상태 점유도와 로컬 거부 비용을 결합해 시퀀스별 EDR 손실 bLEDR(q; x)=1+∑_{t=1}^L ∑_{n=0}^{t-1} ω^{q}_{n,t}(x<t) c^{q}_{n,t}(x<t)를 정의하고, 타깃 분포에 대해 평균하면 전체 기대 라운드 수 E[T^{q}]와 정확히 일치함(EDR 정의 및 정리).
* 여기서 c^{q}_{n,t}는 EOS를 제외한 정상 토큰에 대해 pt와 q_{n,t}의 편차(정규화된 TV 형태)로 표현됨.
* (3) EDR 손실의 그래디언트를 직접 미분하면 점유도 재귀를 전부 역전파해야 해 비용이 크므로, MRP의 가치함수 V^{q}_{n,t}(x)을 정의하고 벨만 방정식으로부터 '한-스텝 TD' 형태의 그래디언트(∇θbLEDR = ∑ ω_{n,t}[∇θ c_{n,t} + ∇θ A_{n,t} (V_{n,t+1}-V_{t,t+1})])를 유도해 지역 파라미터 미분만 필요하도록 함.
* (4) 학습 시에는 알고리즘 1 방식으로: 타깃 모델에서 배치 롤아웃을 얻고(pt(·\|x<t)를 배치로 계산), 각 롤아웃에 대해 A_{n,t}, c_{n,t}를 계산하고 정방향 점유도 ω 및 역방향 가치 V를 계산(해당 값들은 그래디언트 경로에서 stop-gradient 처리), TD 형태 손실로 파라미터만 업데이트함.
* (5) 부가적으로 동일 타깃 롤아웃에서 드래프터별로 기대 라운드와 위치별 수락률을 정확히 계산하는 오프라인 추정량(τ^{q}_{off}(x)=∑_t ω_{t,t+1})과 T_{≥k} 통계 및 AR_k을 도출함.
* 구현상의 세부: 고정 최대 앵커(최대 512) 선택을 위한 중요도 샘플링, 블록 크기 B 고정(실험에서는 B=7) 등을 사용함.

## 주요 결과

- 주요 실험은 DSpark(반자율 드래프터)와 DFly(반자율 드래프터)를 각각 Qwen3-4B, Qwen3-8B 타깃 모델과 페어로 사용해 EDR로 한 에폭 파인튜닝한 결과이다. 학습 데이터는 Open-PerfectBlend이고 각 롤아웃은 타깃 모델에서 샘플링해 사용함(DSpark 설정: 타깃 T=0.7, top-p=0.8, top-k=20; DFly 설정: 타깃 T=1.0, 컷오프 없음).
- 표준화된 오프라인 추정(MAL) 결과(블록 크기 B=7, 동일 타깃 롤아웃에서 비교): DSpark (Qwen3-4B)에서 기존 공개 드래프터 대비 E2E와 EDR의 MAL 변화 예: GSM8K: baseline 6.23 → E2E 6.32 → EDR 6.32; AIME25: 5.46 → 5.57 → 5.59; LiveCodeBench(LCB): 5.46 → 5.54 → 5.56; 챗 벤치(Alpaca, Arena-Hard): baseline 3.62/3.59 → EDR 3.70/3.70. DFly (Qwen3-8B)에서 일부 예: GSM8K: 6.30 → 6.34 → 6.35; AIME25: 5.15 → 5.18 → 5.22; LCB: 5.23 → 5.26 → 5.29; 챗 벤치(Alpaca/Arena-Hard): 3.45/3.18 → 3.52/3.25.
- 전반적 관찰: EDR 파인튜닝은 두 SOTA 드래프터(DSpark, DFly)와 여러 벤치마크(수학·코드·챗)에서 한 에폭 파인튜닝만으로 평균 수락 길이(MAL)를 일관되게 향상시켰으며, E2E(블록-로컬 서로게이트) 대비 동일하거나 더 큰 개선을 보였다(실험 표의 모든 항목에서 EDR ≥ E2E).

## 한계

- 저자가 명시한 한계: (i) 현 프레임워크는 고정된 드래프트 블록 크기 B에 초점을 맞추었으며 적응형 블록 크기(라운드마다 동적으로 선택)는 다루지 않음. (ii) EDR 계산을 위해 점유도 ω와 가치 V를 여러 앵커에 대해 계산해야 하므로 블록-로컬 목적 대비 계산 비용이 더 크다. (iii) MAL(또는 최적 가능한 가속률)은 타깃 분포에 따라 크게 달라지며, 어떤 타깃 분포가 더 어려운지에 대한 이론적 완전 분석은 제공하지 않음.
- 본문에서 합리적으로 확인되는 실험적 제약(저자가 직접 언급하지 않은 범위·재현성 관련 한계): (iv) 실험은 두 드래프터(DSpark, DFly)와 두 규모의 Qwen3 타깃(Qwen3-4B, Qwen3-8B)에서만 수행되었고 블록 크기는 B=7로 고정되어 있어 결과의 범용성(다른 모델·블록 크기·샘플링 설정)에 대한 평가가 제한적임. (v) 학습은 한 에폭만 수행했고(논문과 표에 명시), 더 긴 재학습·다양한 하이퍼파라미터 영향은 보고되지 않음.

- 재현·구현: EDR은 타깃 모델에서 미리 샘플된 롤아웃과 해당 롤아웃에 대한 타깃 조건부 분포 pt(·|x<t)를 입력으로 받아 학습 가능하다. 학습 단계는 (a) 한 배치의 타깃 롤아웃을 타깃 모델로 한 번에 평가해 pt들을 얻고, (b) 각 앵커 n에 대해 q_{n,t}로부터 A_{n,t}, c_{n,t}를 계산하고 정방향 점유도 ω를 재귀적으로 계산한 뒤 역방향으로 가치 V를 계산해 TD 형태 손실로 파라미터만 업데이트하는 순서이다(Algorithm 1). 구현 시 pt 계산을 병렬화하면 효율적이다.  
데이터·롤아웃 요구사항: 학습은 타깃 모델 롤아웃을 필요로 하므로 드래프터 학습을 위해 타깃 모델 접근(추론 비용)이 필요하다. 오프라인 평가자(bTD, AR_k)는 동일한 롤아웃 집합으로 여러 드래프터를 공정하게 비교할 수 있어 평가 효율이 높다.
계산 비용·스케일링: ω와 V 계산이 블록-로컬 목적보다 비용이 크므로 대규모 데이터·큰 B·많은 앵커를 쓸 경우 추가 비용이 발생한다. 논문은 앵커를 최대 512개로 제한하고 중요도 샘플링으로 무작위 선별하는 방식을 제안해 실전 비용을 제어함(중요도 보정으로 그래디언트의 편향 없음 보장).  
학습 안정성·하이퍼파라미터: EDR 자체는 추가 스케일링 하이퍼파라미터를 도입하지 않으며(무보조 하이퍼파라미터), 학습은 TD-형 손실에서 ω와 V를 stop-gradient로 처리해 지역 미분만 수행한다. 논문은 학습률(3e-5), 옵티마이저(AdamW), 배치 사이즈(96) 등 표준 설정을 사용함(Table 3).
배포·추론: 제안된 학습은 드래프터 아키텍처나 추론 절차를 변경하지 않으므로(논문 실험에서 구조·추론은 불변) 학습된 드래프터를 기존의 자기-스펙큘레이티브(self-speculative) 파이프라인에 그대로 적용할 수 있다.  
안전성·정확성: 거부-샘플링(rejection-sampling) 검증 때문에 출력 분포는 드래프터에 관계없이 타깃 모델 분포 p를 정확히 유지하므로 품질-정합성(truthfulness)은 보장된다. 단 학습·추론 중 타깃 모델 접근이 필요하므로 비용·대응성(throughput) 고려 필요하다.

## 개발자 관점

- (중복 방지) EDR은 추가 하이퍼파라미터 없이 전체 기대 라운드 수를 정확히 최소화하는 목표를 제공하며, 동일한 타깃 롤아웃으로 여러 드래프터를 쌍비교할 수 있는 정확한 오프라인 평가기를 제공한다.
