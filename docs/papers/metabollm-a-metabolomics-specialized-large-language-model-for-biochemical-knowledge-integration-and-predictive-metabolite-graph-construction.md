## 한 문장 요약

대규모 대사체학 지식(KEGG/HMDB/PubChem/SMPDB)을 통합해 지속적 사전학습(CPT), 지도미세조정(SFT), 구조화된 검색(RAG)으로 적응시킨 전용 LLM(MetaboLLM)을 개발하고, 이로부터 생성한 검색-근거 대사물질 설명을 임베딩 유사도로 연결해 그래프를 만들고 GIN으로 환자 수준 예측(MetaboLLM-GIN)을 수행한다.

## 해결하려는 문제

대사체학 지식은 KEGG·HMDB·PubChem·SMPDB 등 서로 다른 형식과 식별자를 가진 이질적 자원에 분산되어 있어 일관된 예측 표현으로 통합하기 어렵다. 기존 의학·생물의학에 적응된 LLM들은 문헌·임상 텍스트에 초점이 맞춰져 있어 ‘대사물질·반응·효소’ 단위의 관계를 포괄적으로 재구성하거나, 생성된 언어 지식을 환자 수준의 그래프 기반 예측에 직접 연결할 수 있는지 불명확하다.

## 핵심 기여

- 공개 데이터베이스(KEGG, HMDB, PubChem, SMPDB)를 정합해 237,243개의 대사물질, 12,323개의 반응, 5,993개의 효소, 2,359개의 경로를 포함하는 통합 대사체학 코퍼스 및 템플릿 기반 학습 샘플을 구축함.
- 대규모 백본(Qwen3, Gemma, Llama 등)에서 대사체학 전용 적응을 위해 지속적 사전학습(CPT)과 지도형 미세조정(SFT)을 적용하고, 구조화된 검색(RAG)을 결합한 MetaboLLM을 개발함.
- 대사체학 전용 지표(지식 회수·클래스·관계·설명 생성)로 구성된 새로운 지시·평가 벤치마크를 만들고, MetaboLLM이 대응되는 기본·의학적 모델과 CPT 전 모델을 일관되게 능가함을 보임.
- MetaboLLM이 생성한 검색-근거 대사물질 설명을 임베딩 유사도로 연결해 지식-정보화된 대사물질 그래프를 구성하고, 해당 그래프를 GIN에 적용한 MetaboLLM-GIN이 환자 수준 분류(심장 우회수술 후 스트레스 고혈당 예측: AUC 0.8616, 호르몬 요법 분류: AUC 0.8123)에서 기존 방법 및 대체 그래프보다 우수함을 보임.
- 모델 해석(중요 간선의 경로·반응 정합성, 중요 노드의 경로 풍부도 분석)을 통해 예측에 사용된 그래프 요소들이 생물학적으로 일관된 프로세스(예: 담즙산·레티노이드·스테로이드 대사 등)에 집중됨을 제시함.

## 접근 방법

* (1) 통합 코퍼스 구축: KEGG, HMDB, PubChem, SMPDB 레코드를 교차 정렬해 엔티티(대사물질, 반응, 효소, 경로)를 연결하고 템플릿 기반 자연어 샘플로 변환(총 237,243 대사물질 등).
* (2) 모델 적응: 네 가지 백본(Qwen3-4B 주 모델 포함)을 대상으로 우선 CPT(지속적 사전학습) 수행 후 SFT(지도 미세조정)를 적용해 MetaboLLM을 획득.
* CPT/SFT 하이퍼파라미터는 보조자료에 제시(예: CPT lr 3e-5 epochs 2, SFT lr 2e-5 epochs 3, max seq len 8192 등).
* 디코딩은 greedy(temperature=0)이며 MCQ/SA 태스크의 형식 오류를 줄이기 위해 응답 접두사 사용.
* (3) 구조화된 검색(RAG): Qdrant 벡터 DB에 세 개 컬렉션(화합물·반응·경로)을 구성하고 메타데이터-필터링(먼저 반응 연관 후보, 다음 경로 연관 후보) 후 임베딩 유사도로 상위 후보 선택.
* RAG 프롬프트는 입력 메타볼라이트, 관련 반응·경로 컨텍스트, 출력 형식 지침을 포함.
* (4) 그래프 생성: 각 측정 대사물질마다 MetaboLLM으로(검색을 포함해) 서술문 생성, 서술문을 임베딩해 코사인 유사도로 대사물질 쌍을 순위화한 뒤 상위 k 쌍(데이터별로 밀도 민감도 분석을 통해 CABG 200 edges, MTBLS136 100 edges 선택)으로 토폴로지 구성.
* (5) GIN 학습: 샘플별 대사물질 농도를 노드 피처로 할당하고 GIN으로 그래프-레벨 표현 학습(하이퍼파라미터: CABG hidden_dim 96, layers 2, dropout 0.5, lr 0.0006, epochs 50, 5-fold CV; MTBLS136 hidden_dim 80, layers 3, dropout 0.75, lr 0.0002, epochs 50, 80/20 holdout).
* (6) 평가 및 해석: 내부 메타볼로믹스 벤치마크(12 MC/SA 태스크 + 설명 태스크), 외부 MetaBench 전이, 그래프 대체(무작위·상관·경로·반응) 비교, GNNExplainer로 중요 간선 추출 및 경로·반응 일치 및 노드별 경로 풍부도 분석.

## 주요 결과

- 통합 코퍼스 구성: 237,243개의 대사물질, 12,323개의 반응, 5,993개의 효소, 2,359개의 경로(본문 Fig.1·설명).
- 내부 지식·관계 태스크(12개의 MC/SA 태스크)에서 MetaboLLM-Qwen3-4B가 평균 정확도 79.07%(표 2, MetaboLLM-Qwen3-4B mean≈79.1%)로 가장 높았고, 모든 MetaboLLM 변형이 해당 백본의 CPT-only 및 미적응 모델, 그리고 다수의 의료 도메인 모델을 능가함(본문, Table 2).
- 자유서술(설명) 과제에서 MetaboLLM-Qwen3-4B의 BERTScore-F1: 대사물질(MDesc) 91.71, 경로(PathDesc) 88.04, 효소(EnzDesc) 84.12, 구조-풍부(RichDesc) 87.79, 구조-빈약(PoorDesc) 88.06(본문 Table 3).
- 검색 증강(RAG) 효과: 동일 구조-풍부 대사물질에 대해 MetaboLLM-Qwen3-4B의 RichDesc BERT-F1은 검색 없을 때 86.03 → 검색 시 87.79로 향상(본문 Table 4).
- 외부 벤치마크(MetaBench) 전이: MetaboLLM-Qwen3-8B가 Knowledge 태스크 정확도 56.42%, MetaboLLM-Qwen3-4B의 Pathway description BERT-F1는 85.19로 보고된 최고 성능 중 하나(본문 Table 5). 저자들은 MetaBench가 공개 자료에서 구축되어 내부 지식과 겹칠 수 있음을 명시(본문).","환자 수준 예측 성능: CABG 코호트(61명, 스트레스 고혈당 36명, 비발현 25명)에서 MetaboLLM-GIN AUC = 0.8616 ± 0.0297으로 평가된 모든 예측·그래프 기반·LLM 변형 대비 유의하게 우수(본문 Fig.3a, Table 6; 모든 비교 p<0.0001). 정확도 0.8189, 민감도 0.8139, 특이도 0.8260 보고됨(표 6).","그래프 밀도 민감도: CABG에서 edge 수를 100→500으로 변화시킬 때 최고 AUC는 200 edges에서 관찰되었고, 그 값이 이후 비교 실험의 표준으로 사용됨(본문 Fig.3b).","그래프 구성 비교: 동일 GIN 아키텍처에서 무작위·상관·경로·반응 기반 그래프(밀도-매칭 200 edges)와 LLM 유도 그래프 변형을 평가한 결과 MetaboLLM+RAG 유도 그래프가 최고 성능을 보였음(본문 Table 6).","중요 간선의 생물학적 타당성: GNNExplainer로 순위된 간선들의 Precision@k(경로)는 0.82–1.0 범위로 높게 유지되었고, 반응 정합성은 낮았으나 무작위 그래프 대비 유의미하게 높았음(본문 Fig.3c). 무작위 그래프의 경로 매치 평균은 0.0640, 관찰치는 훨씬 높아(p<0.0001).","노드 중요도 기반 경로 풍부도: CABG 상위 100개 중요한 대사물질은 primary bile acid biosynthesis(11/39, p=0.0009), 관련 선천성 담즙산 합성 결손(10/34, p=0.0009), Vitamin A deficiency(6/14, p=0.0010), retinol metabolism(6/15, p=0.0012) 등으로 유의한 풍부도 관찰(보조표 3).","MTBLS136 호르몬 요법 분류(669명, 에스트로겐 단독 332 vs 에스트로겐+프로게스틴 337)에서 MetaboLLM-GIN AUC = 0.8123 ± 0.0318, 정확도 0.7627, 민감도 0.7456, 특이도 0.7803로 모든 비교 모델보다 유의하게 우수(본문 Table 7, p ≤ 0.0152).","MTBLS136 그래프 최적 edge 수는 민감도 분석으로 100 edges로 선택되었고, LLM 기반 MetaboLLM+RAG 그래프가 여타 그래프·모델을 앞섬(본문 Table 7)."],

## 한계

- 저자 언급: MetaBench는 공개된 대사체 자원에서 구축되어 MetaboLLM이 학습에 사용한 지식과 겹칠 수 있으므로 외부 전이는 '전이 가능성'을 보여주나 완전한 독립성(independence)을 의미하지 않음(본문).
- 저자 언급: 반응 수준의 생물학적 정합성 평가는 제한된 수의 주석 가능 간선에 기반해 수행되어 반응-수준 평가의 표본 수가 작았음(본문 Discussion 및 결과).
- 확인되는 한계(본문 근거): 구조-풍부 대사물질은 전체 코퍼스의 소수에 해당함(구성 기준에서 구조-빈약이 237,243 중 224,226로 94.51%), 따라서 RAG 기반 설명 및 그로 인한 그래프 질은 풍부한 주석을 가진 소수의 대사물질에 더 큰 영향을 받을 가능성이 있음(보조자료 B.3.5).
- 확인되는 한계(본문 근거): 환자 수준 적용 예시는 CABG 코호트(61명)와 공개 MTBLS136(669명) 두 실험으로 타당성을 보였으나, 더 다양한 질환·코호트·플랫폼(예: 다른 측정 기술·주석 밀도)에서의 일반화 가능성은 추가 검증이 필요함(실험 설정·데이터 설명 근거).

## 개발자 관점

- 재현성 확보를 위해 논문이 제공한 세부 하이퍼파라미터 활용: CPT 예시(lr 3e-5, epochs 2, batch 4, max seq len 1536), SFT 예시(lr 2e-5, epochs 3, batch 2, max seq len 8192) 및 MetaboLLM-GIN 하이퍼파라미터(CABG: hidden_dim 96, GIN layers 2, dropout 0.5, lr 0.0006, epochs 50, 5-fold CV; MTBLS136: hidden_dim 80, layers 3, dropout 0.75, lr 0.0002, epochs 50)를 우선 적용하면 논문 결과와 가장 근접한 재현이 가능함(보조표 5–6, 8–9).
- 검색 인프라: RAG 파이프라인은 Qdrant 벡터 DB의 3개 컬렉션(화합물·반응·경로)과 메타데이터-필터링(반응 기반 후보 → 경로 기반 후보) 이후 임베딩 랭킹을 사용함. 보조표 7의 검색 파라미터(Max Reaction Metabolites 3, Max Pathways 3, Metabolites per Pathway 1, bio/chem weight 0.5 등)를 복제하면 유사한 컨텍스트 회수 동작을 얻을 수 있음.
- 프롬프트·출력 지침: RAG 프롬프트 구조(## Task, ## Input Metabolite, ## Reactions, ## Pathways, ## Output Format)와 출력 포맷 규칙(문단형, 전개 통합, 서술형 설명 등)을 재현하면 모델의 형식 준수와 품질 향상에 도움이 됨(부록 B.3.3–B.3.4).
- 그래프 구성 실무: 임베딩 유사도 기반 상위 쌍을 edge로 선택할 때 데이터별 밀도 민감도 분석을 수행(예: CABG은 200 edges 최적, MTBLS136은 100 edges 최적)하고, 너무 조밀한 그래프는 성능 저하 가능성을 염두에 둘 것(본문 Fig.3b 및 민감도 분석).
- 평가·해석: 동일 GIN 아키텍처에서 무작위·상관·경로·반응 기반 그래프와 비교해 MetaboLLM-GIN의 이점을 검증하고, GNNExplainer를 사용해 중요 간선을 추출하여 경로·반응 정합성 및 노드 기반 풍부도 검정을 수행하면 생물학적 유의성을 확보할 수 있음(본문 방법·결과).
