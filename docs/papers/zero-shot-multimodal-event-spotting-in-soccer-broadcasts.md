## 한 문장 요약

사전 학습된 범용 멀티모달 모델을 프롬프트 기반으로 활용해 축구 방송 전체에서 15초 중첩 클립의 시각적 스토리보드와 동기화된 해설을 함께 입력해 이벤트 검출·분류·시계열 국소화(temporal localization)를 제로샷으로 수행하고, 검출 결과를 통합해 하이라이트용 흥분도 점수와 자연어 근거를 생성한다.

## 해결하려는 문제

기존 축구 이벤트 스포팅 방법은 SoccerNet 등 도메인 특화 데이터로 학습된 모델에 의존해 대량 주석·학습·계산 자원이 필요하고, 방송 편집(리플레이·하이라이트)·짧은 이벤트·유사 클래스(shot vs miss) 구별 등에서 일반화가 어렵다. 본 논문은 태스크별 파인튜닝 없이 범용 멀티모달 LLM이 전체 경기 방송에서 이벤트를 검출·분류·시간 국소화할 수 있는지(제로샷 가능성), 입력 표현·프롬프트 구조의 영향, 기존 감독 학습 기반 방법과의 비교, 하이라이트 선출을 위한 흥분도 평가 등을 질문(RQ1–RQ5)으로 제기한다.

## 핵심 기여

- 제로샷 멀티모달 이벤트 스포팅 과제를 전체 경기 방송(검출·분류·시간 국소화 포함)으로 공식화하고 클립 분할·스토리보드·해설 동기화·후처리 파이프라인을 제안함.
- 시각적 스토리보드(15프레임·5×3 그리드)와 동기화된 해설을 범용 멀티모달 모델에 입력해 제로샷으로 이벤트 라벨·클립 상대 타임스탬프·신뢰도·증거를 구조화된 출력으로 얻는 프레임워크를 제시하고, 스토리보드가 프레임별 입력 대비 추론 비용을 72% 절감함을 보임.
- 프롬프트 구조(수동 설계, 두-프롬프트 분해)와 자동 최적화(GEPA, MIPROv2)가 정밀도·재현율·시계열 정밀도에 미치는 영향을 실험적으로 분석함.
- 세 경기(총 130 이벤트)에서 여러 상업·오픈모델(GPT-5.5, GPT-5.6 variants, Qwen3.5-4B, Qwen3-VL-8B Embedding)과 SoccerNet 기반 감독학습 기법(CALF, NetVLAD++)을 동일 6-클래스 평가 프로토콜로 비교해 최고 구성(GPT-5.5+스토리보드)은 F1@5s=72.02%를 달성하며 Cross-dataset 비교에서 감독학습 기반 방법들보다 우수함을 보임.
- 흥분도 점수화(Sexc = 0.4·Sevent + 0.35·Svisual + 0.25·Stext)를 도입하고 각 검출 이벤트에 대해 자연어 근거와 함께 점수를 생성·검증(FlowJudge, GPT-judge)해 순위 일관성을 평가함.

## 접근 방법

* 파이프라인: 1) 입력 전처리—전체 경기 V를 15초 길이, 5초 오버랩 클립으로 분할(클립당 15프레임 균등 샘플링, 각 프레임 384×216으로 리사이즈), 샘플 프레임을 시간순으로 5×3 그리드(1920×648)로 합쳐 스토리보드 생성, Whisper Medium으로 해설 전사 및 클립 정렬.
* 2) 멀티모달 추론—스토리보드(또는 개별 프레임)+동기화된 해설을 범용 멀티모달 모델에 제공하여 구조화된 출력(검출 유무, 이벤트 카테고리, 클립 상대 타임스탬프 τ̂∈[0, clip_length], 신뢰도, 시각·문자 증거)을 얻음.
* 3) 절대 시간 매핑—각 예측의 절대시간 t̂abs = tstart_i + τ̂_i로 변환.
* 4) 시간 통합—중복 예측은 동일 클래스별로 시간순 정렬 후 클러스터링(기본 20s 윈도우, 골·코너는 30s)하여 클러스터별 최고 신뢰도 예측만 보존(이종 클래스는 병합하지 않음).
* 5) 프롬프트 전략—수동 설계형 스토리보드 프롬프트(이벤트 분류 규칙·재생/요약 구분 지침 포함), 두-프롬프트(인식→검증) 분해, GEPA·MIPROv2로 레이블 기반 프롬프트 최적화 실험(모델 파라미터 동결).
* 6) 흥분도 산출—GPT-5.4 Mini가 이벤트 중요도·시각 강도·대사 강도를 가중합(w1=0.40,w2=0.35,w3=0.25)해 Sexc 계산 및 자연어 설명을 생성.
* 평가 지표는 Precision@5s/Recall@5s/F1@5s, mAP@5s, MAE(매칭 허용오차 ±5s 기본).

## 주요 결과

- 데이터셋: 공개 YouTube 다중 카메라 전문 방송 3경기(수동 주석, 6클래스: goal, shot, miss, corner, kickoff, yellow card), 총 130 주석 이벤트.
- 최고 성능: GPT-5.5 + Storyboard 설정이 평균 Precision@5s=63.85%, Recall@5s=82.61%, F1@5s=72.02%, mAP@5s=76.24%, temporal MAE=0.27s를 기록함(세 경기 평균, Table I).
- 비교 대상: SoccerNet으로 학습된 CALF와 NetVLAD++를 동일한 6-클래스·±5s 평가로 교차-데이터셋 테스트한 결과, NetVLAD++는 P@5s=27.23%, R@5s=65.96%, F1@5s=38.49%, mAP@5s=56.82%, MAE=0.81s, CALF는 P@5s=12.91%, R@5s=43.06%, F1@5s=19.60%로 본 논문의 최상위 제로샷 결과보다 낮음(Table I).
- 입력 표현 효과: 단일 경기 어블레이션(GPT-5.6)에서 transcript만 입력 시 F1@5s=50.00%, 15프레임만으로 63.57%, 프레임+대사 72.31%, 스토리보드+대사 73.91%로 멀티모달 조합과 스토리보드가 성능과 비용(프레임별 입력 대비 비용 $64.69→$18.01, 72.2% 절감)에 유리함(Table III).
- 프롬프트 최적화: 수동 스토리보드 프롬프트가 세 경기에서 Recall@5s=82.45%, F1@5s=70.05%로 최고 성능을 보였고, GEPA·MIPROv2는 시간 정밀도(MAE)를 개선했으나 전체 F1은 일관되게 향상되지 않았음(Table IV, V).  MIPROv2는 더 높은 커버리지(Recall 80.37%)를 보였고 GEPA는 MAE 개선(0.23s)을 보임.  두-프롬프트는 정밀도(62.24%)는 올렸으나 재현율 하락으로 F1 감소(Table IV).

## 한계

- 저자 명시 한계: 평가가 공개된 유투브 3경기(세 경기·130 이벤트)에 국한되어 있어 리그·방송 스타일·해설 조건 전반으로의 일반화가 제한적임; 희소 프레임 샘플링은 짧은 지속 시간의 시각 단서를 누락할 수 있음; 리플레이·요약(recap) 콘텐츠가 거짓 양성 발생의 원인이며 프롬프트 기반 방송상태 추론은 완전하지 않음; 흥분도 평가는 모델 기반으로 인간 평가가 필요함; CALF·NetVLAD++와의 비교는 교차-데이터셋 전이 평가임을 명시함.
- 본문에서 합리적으로 확인되는 추가 제약: 실험은 API 기반 상업용 멀티모달 모델(GPT-5.x 등)과 AWS 환경에서 수행되어 재현 시 API 접근·비용 제약이 큼(논문에 모델별 비용/예측 수치 표기); 스토리보드 샘플링(15프레임·5×3 배열)·클립 길이(15s)·오버랩(5s)·클러스터 윈도우(20s/30s)·매칭 허용오차(±5s) 등 하이퍼파라미터 민감도가 존재하며 다른 설정에서 성능 변동 가능성이 큼; Qwen 계열은 성능이 낮아 로컬 경량 모델 만으로 동등 성능 재현 어려움.

## 개발자 관점

- 재현성: 저자들이 제공한 세 경기 영상 URL·주석·평가 메타데이터가 공개되어 있어 동일 데이터로 재현 가능하지만, 상용 멀티모달 모델(GPT-5.x 계열)에 대한 API 접근과 비용을 확보해야 함. 오픈 대안으로 Qwen3.5-4B를 평가했으나 성능이 크게 낮았음(Table I).
- 입력·전처리: 권장 기본 설정은 클립 길이 15s, 오버랩 5s, 클립당 15프레임 균등 샘플링, 프레임 리사이즈 384×216, 5×3 스토리보드(1920×648) 구성, Whisper Medium으로 해설 전사—이 설정이 성능·비용 균형에 대해 저자 실험에서 기본값으로 사용됨.
- 비용·성능 트레이드오프: 스토리보드는 개별 프레임 입력 대비 추론 비용을 약 72% 절감하면서 F1을 소폭 개선하거나 유지하므로 실전 배포 시 스토리보드가 실용적임. 다만 최고 성능은 GPT-5.5/GPT-5.6 Sol 등 고성능 모델에서 관찰되어 비용 관리 필요(논문에 모델별 Cost/match 표기).
- 프롬프트·후처리: 프롬프트 구조(수동 vs 자동 최적화, 두-프롬프트 분해)가 정밀도/재현율/시간 정밀도에 뚜렷한 영향을 주므로 운영 환경에 맞춰 프롬프트·임계치(신뢰도 컷오프)·클러스터링 윈도우(20s/30s)를 튜닝해야 함. 자동 프롬프트 최적화는 일부 클래스·MAE 개선에 유용하나 입력의 증거 부족은 보완하지 못함.
- 리플레이·방송상태 처리: 리플레이/요약으로 인한 중복/허위 검출을 줄이려면 단순 프롬프트 지침 대신 방송상태(broadcast vs recap) 신호(예: 편집 메타데이터, 오디오·그래픽 특징, 카메라 각도·슬로우모션 탐지) 모델링을 도입할 필요가 있음.  또한 흥분도 점수는 모델 기반 정렬에 좋은 초기 방법이나 사람 심사자와의 정합성 검증을 배포 전 필수로 수행해야 함.
